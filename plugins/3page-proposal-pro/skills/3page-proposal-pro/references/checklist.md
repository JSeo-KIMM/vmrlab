# 최종 품질 체크리스트

출력 직전 다음 항목을 모두 확인한다.

## 구조

- [ ] 대제목 1.~7. 번호·제목 원문과 일치
- [ ] 소제목 번호 체계 정합(6.1/6.2 등 상위번호 일치)
- [ ] 소제목 깊이 3단계 이내

## 문체

- [ ] 모든 문장이 개조식 종결(~함/~임/~하고자 함)
- [ ] 서술형 종결(~이다/~한다/~했다) 0건
- [ ] 주관적 수식어("매우", "엄청난", "놀라운") 0건

## 분량

- [ ] A4 3장(한글 기준 약 4,500~5,500자) 이내
- [ ] 섹션별 배분 준수 (2절 0.4장 / 3절 0.6장 / 4절 1.0장 / 5~7절 합 1.0장)

## 내용 완성도

- [ ] 초안의 `[...]`, `...`, TBD 메모 모두 해결(보완 또는 `[출처 확인 필요]` 표기)
- [ ] 모든 정량 수치에 출처 또는 근거 제시
- [ ] 4.2 연구개발내용과 4.3 검증방안이 Step 단위로 명시적 매핑
- [ ] 5절 정량 목표 지표가 측정 가능(Measurable)
- [ ] 7.1 연구/기술적 효과 불릿 2개 이상

## 표기 일관성

- [ ] 영문 약어 최초 등장 시 병기, 이후 약어만 사용
- [ ] 숫자·단위 표기 통일(5N, 80%, 3년차)
- [ ] 이미지 Obsidian 임베드 구문 유지
- [ ] 표는 마크다운 표 문법

## 오탈자 자동 점검 대상

초안에서 자주 발견되는 오탈자:
- "연구개발발내용" → "연구개발내용"
- "레포트 생성성" → "리포트 생성"
- "visuomotory" → "visuomotor"
- 중복 공백, 문장 끝 중복 종결어미

## 출력

- [ ] UTF-8 인코딩
- [ ] GFM 마크다운
- [ ] 파일명 컨벤션 준수(`<원본이름>_v<n>.md` 또는 사용자 지정)
