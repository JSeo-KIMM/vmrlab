# 재사용 템플릿 (templates)

## 1. 정량 목표 표 (5절)

```markdown
| 지표 | 목표값 | 측정 방법 | 비고 |
|---|---|---|---|
| (전체 성공률) | N% 이상 | (전체 시나리오 완수율) | 세계 최고 수준 부재 시 FOAK |
| (핵심 정확도) | ±N% 이내 | (전문가 대비 오차) |  |
| (안전성) | N 이하 | (최대 접촉력/시간) |  |
| (일치율) | N% 이상 | (전문가 판독 대비) |  |
```

## 2. 연차별 로드맵 (6절)

```markdown
| 연차 | 주요 내용 | 검증 대상 | 마일스톤 |
|---|---|---|---|
| 1년차 | Feasibility 확보 | 팬텀/시뮬레이션 | 시스템 통합 완료 |
| 2년차 | 제한 조건 실증 | 연구자·제한 IRB | 핵심 지표 80% 달성 |
| 3년차 | 일반 환경 확장 | 병원 IRB 임상 | 최종 지표 달성 및 논문·특허 |
```

## 3. 한계 ↔ 차별성 매핑 표 (3.2)

```markdown
| 기존 기술 한계 | 본 연구 차별성 |
|---|---|
| (한계 1) | (해결 방안 1) |
| (한계 2) | (해결 방안 2) |
```

## 4. 연구개발내용 블록 (4.2)

```markdown
* **[블록명]**
    * **개발목표**: (한 문장)
    * **핵심 요소기술**
        * **(키워드1)**: (설명)
        * **(키워드2)**: (설명)
    * **예상 결과물**: (산출물 명시)
```

## 5. 용어 대조 표 (프로젝트 시작 시 정의)

```markdown
| 용어 | 표준 표기 | 비고 |
|---|---|---|
| (영문 원어) | (한글 번역(원어) 최초 1회, 이후 한글) |  |
```

## 6. 기대효과 7.3 성과 목표 템플릿

```markdown
- 논문: SCI 논문 N편 이상 (주제 A, B, C 각 1편+)
- 특허: 국내외 특허 N건 이상 (핵심기술 A, B, C)
- 플랫폼: (범용 프레임워크 이름)
- 대형과제 확장: (후속 사업 방향)
- 언론 홍보: 세계 최초/국내 최초 (홍보 포인트)
- FOAK: (First-of-a-Kind 시연 이벤트)
```
