# 작성 규칙 (writing-rules)

## 1. 문체 — 개조식

- 모든 문장을 "~함 / ~임 / ~하고자 함 / ~필요함 / ~예정임" 등으로 종결
- 서술형(`~이다`, `~한다`, `~했다`) 금지
- 수식어·감탄·주관 표현 제거 ("매우", "놀라운", "엄청" 등 삭제)
- 사실·수치·고유명사 중심

### 변환 예시

| 초안(구어체) | 개조식 변환 |
|---|---|
| 초음파 진단이 표준으로 활용되고 있는 만성 질환이 엄청 많음 | 초음파 영상 진단은 지방간·갑상선·경동맥 등 다수 만성질환의 표준 진단법으로 활용됨 |
| 이런 만성질환 관리를 위해서 ~ 의료 접근성 문제가 존재함 | 의료 소외지역 및 고령 환자는 숙련 전문가가 상주하는 의료기관까지 이동해야 하므로 의료 접근성 문제가 존재함 |

## 2. 분량 배분 (A4 3장 기준)

| 섹션 | 배분 |
|---|---|
| 1. 연구주제명 | 1줄 |
| 2. 연구대상 및 필요성 | 0.4장 |
| 3. 기존 기술 현황 | 0.6장 |
| 4. 연구개발내용 | 1.0장 (핵심) |
| 5. 연구 목표 | 0.3장 |
| 6. 연구 추진 전략 | 0.3장 |
| 7. 기대 효과 | 0.4장 |

초과 시 압축 우선순위: 4.2 하위 불릿 → 3.1 동향 → 7절 반복 표현

## 3. 구조 제약

- 대제목(1.~7.) 번호·제목 변경 금지
- 소제목은 3단계 깊이 초과 금지(예: `4.2.1.1` 금지)
- 번호 오류 자동 수정(예: "6." 아래 `5.1`은 `6.1`로 교정)
- 불릿은 `-` 또는 `*` 중 입력 파일 스타일에 맞춰 일관 적용

## 4. 숫자·단위 표기

- 아라비아 숫자 + 단위 직접 붙임: `5N`, `80%`, `3년차`, `5분 이내`
- 범위: `75.6% ~ 90.9%` (공백 양쪽에)
- 소수점: `0.79` (선행 0 표기)

## 5. 기관명·약어

- 최초 등장: 정식명칭(약어) — 예: "한국기계연구원(KIMM)"
- 2회차부터 약어만 사용
- 국제기관은 영문 그대로(BWH, MIT 등)

## 6. 이미지·캡션

- Obsidian 임베드 `![[Pasted image ...png|410]]` 원형 유지
- 각 이미지 아래 캡션 추가 권장: `<그림 1> 제목`
- 표는 마크다운 표 유지, 제목은 `<표 1>` 형식

## 7. 인용·출처

- 정량 수치(유병률·민감도·특이도·AUROC 등)는 출처 필수
- 형식: `민감도 75.6% (Bohte et al., 2011)` 또는 각주 형태
- 출처 미확보 시 `[출처 확인 필요]` 표기로 사용자에게 확인 요청
