# 3page-proposal-pro

한국 정부 연구제안서(기획 단계, A4 3장 내외) 작성 스킬. 구어체 초안을 정부 형식의 개조식 제안서로 변환한다.

## 워크플로우

### Step 1: 입력 분석
입력 초안(.md)을 읽고 다음을 식별한다.
- 7개 표준 대제목(1.연구주제명 / 2.연구대상 및 필요성 / 3.기존 기술 현황 / 4.연구개발내용 / 5.연구 목표 / 6.연구 추진 전략 / 7.기대 효과) 존재 여부
- 빈 구간: `[...]` 메모, `...` 생략, TBD, "더 해야 할게 있으면 추가" 같은 작성자 메모
- 번호 체계 오류(예: "6. 연구 추진 전략" 아래 `5.1`로 시작)
- 이미지 임베드(`![[...png]]`) 위치

### Step 2: 보강 리서치 (필요 시)
초안에 정량 수치·출처·기술 동향이 부족하면 WebSearch로 다음을 확보한다.
- 2절 필요성: 유병률·시장 규모·사회적 수치
- 3.1 동향: 경쟁 연구기관/주요 논문(최근 3년)
- 4.3/5절 검증: 인용 가능한 성능 지표 출처

### Step 3: 변환 규칙 적용
`references/writing-rules.md`(개조식·분량·용어)와 `references/section-guide.md`(섹션별 작성 지침)를 읽고 규칙에 따라 변환한다. 표·로드맵·블록 템플릿은 `references/templates.md`를 참고한다.

### Step 4: 품질 점검
`references/checklist.md`의 전 항목을 확인한 뒤 출력한다.

### Step 5: 출력
- 파일명: 입력이 `foo.md`면 `foo_v<n>.md` 또는 사용자 지정 경로
- UTF-8, GFM(GitHub-Flavored Markdown)
- 이미지 임베드 구문 및 원문 링크 유지

## 필수 불변 사항

- **대제목 1.~7. 번호와 제목은 절대 변경 금지**
- **개조식 종결**: "~함 / ~임 / ~하고자 함" 일관 사용. 서술형 종결(`~이다`, `~한다`) 금지
- **A4 3장 분량 한도**: 초과 시 4.2 하위 불릿 우선 압축
- **이미지 링크 원형 유지**: Obsidian `![[...]]` 문법 그대로

## 참조 파일

- [`references/writing-rules.md`](references/writing-rules.md) — 문체·분량·용어 표준 규칙
- [`references/section-guide.md`](references/section-guide.md) — 7개 대제목별 작성 지침과 보강 포인트
- [`references/checklist.md`](references/checklist.md) — 최종 품질 체크리스트
- [`references/templates.md`](references/templates.md) — 정량 목표 표·연차 로드맵·용어 대조 표 템플릿

## 일반화 주의

본 스킬은 도메인 무관 범용이다. 입력 도메인(의료로봇/AI/소재 등)이 달라도 동일 규칙이 적용된다. 도메인 특화 내용은 Step 2 리서치에서 확보하며 스킬 자체에 내재화하지 않는다.
