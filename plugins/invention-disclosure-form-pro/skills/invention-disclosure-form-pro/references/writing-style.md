# 작성 문체 규칙 (사용자 고유 스타일)

기존 4개 직무발명 내용 설명서에서 추출한 사용자 고유의 문체 규칙. **이 규칙을 어기면 톤이 달라져 사용자가 직접 다시 손봐야 한다.**

## 1. 종결어미

### 표준
- 평서 문장은 **"~함"** 또는 **"~음"**으로 종결
- 명사형 종결도 자주 사용

### 예시 (그대로 사용 가능)
- "...을 측정 가능하도록 하는 발명임"
- "...두 방향의 거리를 조합하여 휘어진 방향과 변위를 계산 가능"
- "...간단명료하게 기재함"
- "...일회용으로 생산가능"
- "...실시간 제어가 가능함"
- "...장점이 있음"
- "...적용함"

### 금지
- "~합니다", "~합니다." (X)
- "~이다.", "~한다." (X — 이 사용자는 평서체보다 명사형 ~함체를 압도적으로 선호)
- "~할 것이다" (X)

### 예외
- 항목 제목, 주석성 가이드는 양식 자체이므로 양식 그대로 ("기재함" 등)
- 4번 구성 부분의 컴포넌트 설명은 한 단락 평서체로 풀 수도 있음 (예시 4번 "스튜어트 플랫폼" 사례 참조). 이 경우에도 마지막은 ~함/~음으로 닫는 게 자연스러움.

## 2. 불릿과 들여쓰기

### 1차 불릿: 하이픈 + 공백
```
- 첫 번째 항목
- 두 번째 항목
```

### 2차 들여쓰기 (계층 구조)
1차 불릿 앞에 공백 1칸을 두는 방식이 사용자 패턴:
```
 - 1차 불릿
  - 2차 불릿 또는 부연 설명
```

### 화살표 인용
종래기술 대비 본 발명의 차이를 강조할 때:
```
 - 종래 기술 X 묘사
 -> 본 특허에서는 Y 방식임
```

### 별표 항목
4번 항목 내부의 하위 섹션 구분에는 별표(`*`):
```
* 본 발명의 목적
 - ...
* 본 발명의 구성
 - ...
```

### 번호 매김
- 5번 권리: `(1) ... (2) ... (3) ...`
- 4번 구성에서 컴포넌트 그룹: `(1) 그룹명` 후 하이픈 불릿
- 2번 배경에서 절차 단계: `1) ... 2) ... 3) ...`

## 3. 문장 길이와 밀도

- 한 불릿 = 한 핵심 정보 = 30~120자 내외
- 너무 짧은 단편 금지 ("좋음", "가능"만 적힌 줄 X)
- 너무 긴 다중 주장 한 줄 금지 — 분리 가능하면 분리

## 4. 키워드 강조 패턴

### 굵은 키워드 + 콜론 + 설명
4번 구성의 컴포넌트 분해에서 자주 사용:
```
회전 인코더:
각 회전 인코더의 회전축에는 첫 번째 링크의 한쪽 끝이 부착되어...
```

### 따옴표 인용
용어 정의나 별칭 부여 시:
- (이해를 돕기 위해 "원통형 유연물체"를 "일회용 면봉"으로 함)

## 5. 도메인 어휘

사용자가 자주 쓰는 표현 (자연스럽게 사용 가능):
- "본 발명", "본 특허"
- "기존 연구 및 특허와 달리"
- "~을 제안함"
- "~을 위한 기구구조"
- "~ 기반의"
- "~을 활용함"
- "~을 도출 할수 있음" (띄어쓰기 그대로 유지)
- "Passive 마커", "Active 타입" 같은 영어 용어 + 한국어 혼용 자연스러움
- 기술 용어 음차 + 영어 병기: "정기구학(forward kinematics)", "정합(registration)"

## 6. 다국어/단위

- 영어 약자는 첫 등장 시 풀어 쓰고 약자 병기
  - 예: "Optical Tracking System(OTS)", "Artificial Neural Network(ANN)"
- 한국어 단위와 영어 단위 혼용 가능 (mm, μm, kg, N 등)

## 7. 표현 톤

### 권장 (사용자 톤에 부합)
- 객관적/기술적 사실 기술
- 비교 대상이 분명한 차별성 명시 ("종래는 ~인데, 본 발명은 ~")
- 정량적 표현 가능하면 정량적으로 ("3개의 코일 스프링", "6개의 입력 노드")

### 비권장
- 감정적 수식어 ("매우 혁신적", "획기적인", "최고의") — 단, "매우 단순한 제작 과정" 같은 사실 기반 강조는 가끔 사용됨
- 모호한 표현 ("좋다", "효율적이다") — 무엇이 어떻게 좋은지 명시
- 불필요한 영어 직역 ("이슈", "솔루션"보다는 한국어 표현 우선)

## 8. 일관성 점검 체크리스트

작성 후 반드시 확인:
- [ ] 모든 평서 문장이 ~함/~음으로 끝나는가?
- [ ] 1차 불릿이 모두 하이픈인가?
- [ ] 4번 구성에서 컴포넌트별 굵은 키워드 패턴이 적용되었는가?
- [ ] 5번 권리가 (1)(2)(3) 번호로 시작하는가?
- [ ] 영어 약자가 첫 등장 시 풀이되었는가?
- [ ] 본문 그림 마커가 6번 추가자료의 캡션과 일치하는가?
