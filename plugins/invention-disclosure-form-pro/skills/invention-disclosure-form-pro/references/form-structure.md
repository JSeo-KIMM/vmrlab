# KIMM 직무발명 내용 설명서 양식 구조

## 전체 골격

문서 최상단에 제목 1줄: `직무발명(고안)내용 설명서`
그 아래 6개 메인 항목이 순서대로 배치됨. **항목 번호와 제목은 절대 변경하지 않음.**

```
직무발명(고안)내용 설명서

1. 발명(고안)의 명칭
2. 발명(고안)의 배경
   (1) 유사특허 또는 출원
   (2) 배경문헌 또는 관련특허
   (3) 발명(고안)과 관련된 본 연구원의 전출원
3. 종래기술의 설명과 그것의 문제점
4. 본 발명의 상세한 설명 (목적/구성/효과)
5. 보호받고 싶은 권리
6. 추가자료
```

## 항목별 작성 규칙

### 1. 발명(고안)의 명칭

- 핵심 키워드 2~4개를 자연스럽게 연결한 한 문장형
- 기능 + 대상 + 방법 패턴이 가장 안정적
- 전문 약자(예: ANN, OTS, CT)는 가급적 풀어 쓰되, 정착된 용어는 허용
- 예시:
  - "유연 원통 소재의 비접촉식 굽힘 변위 및 힘 센싱을 위한 센서의 고안"
  - "방사선 영상 모니터링과 적외선 추적이 가능한 부착 마커"
  - "물리적 자극에 의한 초음파 도플러 영상기반 혈관 후보 영역 검출 방법"
  - "병렬구조 기반 마스터 장치 및 이를 위한 인공지능 기반 정기구학 해석 방법"

### 2. 발명(고안)의 배경

3~7개 하이픈 불릿으로 다음을 서술:
- 어떤 응용 맥락에서 이 발명이 필요한가
- 기존 방식이 어떻게 동작하는가 (필요시 1)~5) 번호 매김으로 단계화)
- 기존 방식의 무엇이 문제인가
- 본 발명이 무엇을 다르게 하려는가 (한 줄 요약)

마지막 줄에는 본 발명이 만족시키고자 하는 요구사항을 1)~3) 번호로 명시할 수 있음.

#### 2-(1) 유사특허 또는 출원

- 출원번호 또는 등록번호 + 명칭 + 출원인 한 줄
- 그 아래 하이픈 불릿으로 1~3줄 요약
- 형식 예:
  ```
  JP6017161B2
   - 카테터 내에 팁의 위치와 처짐을 정확하게 판독할 수 있는 magnetic 코일을 사용하여...
  ```
- 정보가 없으면 "N/A" 또는 빈 칸으로 두고 사용자에게 보완 안내

#### 2-(2) 배경문헌 또는 관련특허

- 논문: 큰따옴표 안에 제목, 연도, 저자 → 한 줄 설명
  - 예: `"Design of a Low-cost Miniature Robot...", 2020, S.Wang et.al. : ...`
- 제품: 제품명, 회사, 출시 시점 + 한 줄 설명
  - 예: `VISICOIL™ MR — Linear fiducial marker for soft tissue tumor localization`

#### 2-(3) 본 연구원의 전출원

- 관리번호 또는 출원번호 + 명칭만 한 줄로 나열
- 예: `10-2017-0106527 원격 초음파 진단시스템`
- 없으면 "N/A"

### 3. 종래기술의 설명과 그것의 문제점

두 개의 서브 섹션으로 구성:

```
* 종래 기술의 설명
 - ...
 - ...
* 본 발명과의 상이점
 - ...
```

또는 종래기술이 여러 갈래라면 다음 패턴 사용:
```
* 종래기술의 설명 및 본 발명과의 차이점
 도플러를 이용한 혈관 검출 종래 기술
 - 종래 기술 묘사
 -> 본 특허에서는 ...
 물리적 자극 및 압박을 이용한 종래 기술
 - 종래 기술 묘사
 -> 본 발명은 ...
```

`->` 화살표는 차이점/대안 강조 시 사용.

### 4. 본 발명의 상세한 설명 (목적/구성/효과)

4개 하위 섹션 고정:

```
* 본 발명의 목적
 - ...

* 본 발명의 구성
 (1) 컴포넌트/단계 그룹명
 - ...
 (2) ...
 - ...

* 본 발명의 장점
 - ...

* 본 발명의 효과
 - ...
```

**구성** 부분 작성 핵심:
- 컴포넌트별로 굵은 키워드(예: `베이스 플레이트:`, `회전 인코더:`) + 줄바꿈 + 설명 패턴 권장
- 또는 알고리즘/단계라면 화살표 `->` 로 흐름 표시
- 그림 참조가 필요하면 본문에 `<그림 N. 캡션>` 마커 삽입 (figure-generation.md 참조)

**장점**과 **효과** 분리:
- 장점: 구조적/기술적 우위 (예: "비접촉식이라 비교적 저렴")
- 효과: 실제 활용 가치 (예: "어린이/노인/비만 환자 등에서 큰 도움")
- 합쳐서 `* 본 발명의 장점 및 효과`로 둘 수도 있음 (사용자 선호에 따라)

### 5. 보호받고 싶은 권리

번호 매김 `(1) (2) (3)` 으로 핵심 보호 항목을 나열:
- 보통 3~5개
- 첫 번째는 가장 핵심적인 구조/디자인 권리
- 그 다음으로 방법/시스템/응용 권리
- 각 권리는 한 문장 또는 한 단락
- 예시 패턴:
  - 구조: "두 개의 수직한 적외선 근접 거리 센서를 이용하여 ... 측정할 수 있도록 하는 센서 디자인"
  - 방법: "X-Y 축 휨 변위를 이용하여 ... 측정하는 알고리즘 및 방법"
  - 시스템: "제안된 ... 장치를 자동 채혈로봇에 통합하는 시스템 구성"

### 6. 추가자료

- 도면, 실험 데이터를 첨부할 때 명시
- 본문에 그림이 있다면: `<그림 3, 제작된 마커의 앞, 뒷면 (좌) 및 ...>`
- 외부 ppt가 있다면: `첨부 ppt 파일 자료 참고`
- 없으면: `없음`

## 시각적 마커 컨벤션

본문 내 그림 인용 패턴:
- `<그림 1. 마커 제작에 필요한 재료 및 제작 방식 모식도>`
- `<그림 2, 마커의 측면 구조>`
- `<그림 3, 제작된 마커의 앞, 뒷면 (좌) 및 피부 부착 된 마커의 X-Ray 촬영 영상(우, 상), 위치추적 장치에 의한 적외선 반사 결과 영상 (우, 하)>`

쉼표/마침표 혼용은 사용자 작성 습관을 따른 것이므로 그대로 유지.
