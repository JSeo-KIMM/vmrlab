# example/ — 양식 예제 폴더

이 폴더에는 자주 사용하는 저널·학회 **논문 양식 파일(`.docx`)** 을 넣어 둡니다.

`paper-style-conversion-pro` skill은 변환 작업 시 이 폴더를 확인하여,
양식 해석이 모호하거나 사용자가 양식 파일을 따로 제시하지 않은 경우
여기 있는 파일을 **참고 자료**로 활용합니다.

## 넣어 두면 좋은 파일

- 자주 제출하는 저널/학회의 공식 논문 템플릿 `.docx`
- 표기법(참고문헌 형식, 수식 번호, 표 스타일)을 보여 주는 예시 원고

## 참고

- 이 폴더가 비어 있어도 변환은 가능합니다 — 사용자가 변환할 때 양식 파일을
  직접 지정하면 그 파일을 사용합니다.
- 예제 파일이 있으면 다음 변환부터 양식 해석 정확도가 올라갑니다.
