  세부 개발목표와 연차별 연구내용을 자동으로 구성합니다.

  사용법:
    /research-plan <파일경로>
    /research-plan <파일경로> --years=<연구기간>
    /research-plan <파일경로> --objectives-only

  옵션:
    --years=N         총 연구기간 (기본값: 3)
    --objectives-only 세부목표만 작성 (연차별 내용 제외)

  예시:
    /research-plan ./draft.md
    /research-plan ./초안.md --years=4
    /research-plan ./아이디어.md --objectives-only

# 연구개발계획서 작성 커맨드

## 실행 절차

### Step 1: 입력 파일 확인
`$ARGUMENTS`에서 파일 경로와 옵션을 파싱합니다.

- 파일이 존재하지 않으면 오류 메시지를 출력하고 종료
- 파일이 존재하면 내용을 읽어 분석 시작

### Step 2: research-plan-pro 에이전트 호출
읽어들인 초안 내용을 바탕으로 `research-plan-pro` 서브에이전트를 호출합니다.

다음 정보를 에이전트에게 전달합니다:
- 원본 파일 경로 및 내용
- 파싱된 옵션 (연구기간, 목표만 작성 여부)
- 출력 파일 저장 경로 (원본 파일과 동일 디렉토리)

### Step 3: 결과 확인 및 안내
에이전트 작업 완료 후:
1. 생성된 파일 목록 출력
2. 주요 세부목표 요약 표시
3. 추가 수정이 필요한 부분 안내

## 에이전트 전달 프롬프트

아래 내용을 research-plan-pro 에이전트에게 전달하세요:

```
다음 초안 파일을 분석하여 정부 제출용 연구개발계획서를 작성해주세요.

[입력 파일]: $ARGUMENTS에서 파싱된 파일 경로
[파일 내용]: (파일 내용 전체)
[연구기간]: --years 옵션값 또는 기본 3년
[작성 범위]: --objectives-only이면 세부목표만, 아니면 전체

작업 완료 후 생성된 파일 경로를 알려주세요.
```
