# 연차별 연구내용 작성 커맨드

## 실행 절차

### Step 1: 세부목표 파일 읽기
`$ARGUMENTS`에서 파일 경로와 옵션을 파싱하고, 세부 개발목표 파일을 읽습니다.

### Step 2: research-plan-pro 에이전트 호출 (연차별 모드)
에이전트에게 다음을 요청합니다:
- 세부목표 파일 내용을 기반으로 연차별 연구내용 작성
- `--year` 옵션이 있으면 해당 연차만 작성
- 없으면 전체 연차 작성

### Step 3: 결과 저장 및 안내
생성된 연차별 연구내용을 마크다운 파일로 저장합니다.
파일명: `[원본파일명]_연차별연구내용.md`

## 에이전트 전달 프롬프트

```
다음 세부 개발목표를 바탕으로 연차별 연구내용을 작성해주세요.

[입력 파일]: $ARGUMENTS에서 파싱된 파일 경로
[세부목표 내용]: (파일 내용 전체)
[총 연구기간]: --years 옵션값 또는 3년
[작성 연차]: --year 옵션값 (없으면 전체 연차)

각 연차별로:
1. 세부목표별 연구내용 (구체적 활동 3~5개)
2. 연차 완료 시 기대 성과물 목록
3. 정량적 달성 지표 표

작성 완료 후 저장된 파일 경로를 알려주세요.
```
