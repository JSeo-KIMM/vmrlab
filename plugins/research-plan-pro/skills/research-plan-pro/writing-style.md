# 개조식 문체 규칙

정부 제출용 연구개발계획서에 적용하는 개조식 문체의 규칙과 예시를 정의함.

---

## 1. 개조식 문체란

핵심 내용을 짧고 명확하게 열거하는 공문서 문체임.
문장 말미를 명사 또는 명사형 어미(`~임`, `~함`, `~됨`, `~함`)로 종결함.
주어 없이 서술어 중심으로 간결하게 기술함.

---

## 2. 문장 종결 규칙

### 허용 어미 (개조식)

| 용도 | 어미 | 예시 |
|------|------|------|
| 상태·정의 서술 | ~임 | 본 연구의 핵심 목표는 자율 스캔 시스템 개발임 |
| 행위·계획 서술 | ~함 | 힘 제어 알고리즘을 설계하고 시뮬레이션으로 검증함 |
| 수동·결과 서술 | ~됨 | 검증 완료 후 실물 로봇에 적용됨 |
| 예정·계획 서술 | ~할 예정임 | 2차년도에 실물 프로토타입을 제작할 예정임 |
| 목표 명사 종결 | 명사형 | 힘-토크 센서 인터페이스 모듈 개발 |

### 금지 어미 (경어체·구어체)

| 금지 표현 | 대체 표현 |
|-----------|-----------|
| ~합니다 | ~함 |
| ~입니다 | ~임 |
| ~합니다. / ~됩니다 | ~함 / ~됨 |
| ~하고자 합니다 | ~하고자 함 |
| ~할 계획입니다 | ~할 계획임 / ~할 예정임 |
| ~했습니다 | ~하였음 |
| ~해야 합니다 | ~해야 함 |
| ~할 수 있습니다 | ~할 수 있음 |

---

## 3. 항목 서술 규칙

### 세부목표·연구내용 항목

- 각 항목은 `-` 또는 번호로 시작함
- 한 항목은 1~2문장 이내로 간결하게 기술함
- 항목 간 중복 없이 각각 독립적인 내용을 담음
- 항목 제목(볼드)은 명사형으로 종결함

### 올바른 예시

```
- 임피던스 제어 알고리즘 설계 및 시뮬레이션 검증: Isaac Sim 환경에서 다양한 체표면 곡률 조건 하에 접촉력 오차 ±1.0 N 이내 달성을 목표로 함
- 힘-토크 센서 인터페이스 모듈 구축: 실시간 데이터 수집 및 제어 루프 연동을 위한 드라이버 개발 완료 예정임
- 파일럿 팬텀 실험 수행: 단순 구면 팬텀 대상으로 접촉력 제어 성능을 정량 평가함
```

### 잘못된 예시 (금지)

```
- 임피던스 제어 알고리즘을 설계하고 시뮬레이션으로 검증합니다. (경어체)
- 힘-토크 센서 인터페이스 모듈을 구축할 계획입니다. (경어체)
- 팬텀 실험을 해서 성능을 평가해볼 것입니다. (구어체)
```

---

## 4. 전문용어 표기 규칙

- 최초 등장 시 한글(영문) 병기: 임피던스 제어(Impedance Control)
- 이후 등장 시 한글 또는 영문 약어 통일 사용
- 약어 정의 후 약어만 사용 가능: 로봇 운영 체제(ROS2), 이후 ROS2 사용
- 외래어는 국립국어원 표기법 준수

---

## 5. 단락 구성 원칙

- 제목: `##`, `###` 계층 사용, 명사형 종결
- 본문: 개조식 항목 열거 우선, 산문체 지양
- 표: 정량 지표, 비교, 일정 표현 시 활용
- 강조: **볼드** 는 핵심 수치·용어에만 한정 사용

---

## 6. 숫자·단위 표기

- 숫자는 아라비아 숫자 사용: 3년, 95% 이상, 30 fps
- 단위는 SI 단위계 우선, 공백 후 단위 표기: 0.5 N, 100 ms
- 퍼센트: % (공백 없이): 95%
- 범위: A 이상 B 이하, A~B 형식 혼용 가능

## 7. 금지 표현 목록

| 금지 표현 유형 | 예시 |
|----------------|------|
| 구어체 | ~거든요, ~인데요, ~한다고 봐요 |
| 모호한 부사 | 대충, 어느 정도, 적당히, 나름 |
| 중복 표현 | 미리 예상하다, 서로 상호작용하다 |
| 감정·주관 표현 | 우수한, 혁신적인, 세계 최고의 (근거 없는 경우) |
| 과도한 피동 | ~되어져서, ~되어지고 |
