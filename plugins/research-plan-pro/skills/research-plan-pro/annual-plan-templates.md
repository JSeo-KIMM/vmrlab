# 연차별 연구내용 작성 템플릿

정부 제출용 연구개발계획서의 연차별 연구내용 작성에 사용하는 표준 템플릿임.
모든 문장은 `writing-style.md`의 개조식 문체 규칙을 준수함.

## 2. 연차별 연구내용 섹션 템플릿

```markdown
## N차년도 연구내용

> **단계**: [단계명] | **주요 목표**: [1줄 요약]

### N-1. [세부목표 1명] 관련 연구

- **[연구내용 항목 1 제목]**: [구체적 연구 활동 기술, 개조식으로 종결함]
- **[연구내용 항목 2 제목]**: [구체적 연구 활동 기술, 개조식으로 종결함]
- **[연구내용 항목 3 제목]**: [구체적 연구 활동 기술, 개조식으로 종결함]
- **기대 성과물**:
  - [결과물 1 — 명사형]
  - [결과물 2 — 명사형]

### N-2. [세부목표 2명] 관련 연구

- **[연구내용 항목 1 제목]**: [내용]
- **[연구내용 항목 2 제목]**: [내용]
- **기대 성과물**:
  - [결과물 1]

### N차년도 목표 달성 지표

| 세부목표 | 평가 항목 | 목표치 | 측정 방법 |
|----------|-----------|--------|-----------|
| 세부목표 1 | [항목] | [수치] | [방법] |
| 세부목표 2 | [항목] | [수치] | [방법] |
```

## 3. 연구내용 항목 작성 기준

### 항목 구성 기준

- 세부목표당 연구내용 항목: 3~5개
- 각 항목은 독립적이고 중복 없이 구성함
- 항목 제목은 명사형으로 간결하게 기술함
- 항목 내용은 1~2문장 이내로 구체적으로 기술함

### 연차별 연구 심화 원칙

**1차년도**: 설계·개념 검증 중심 표현
- "~알고리즘 초기 설계 및 시뮬레이션 검증 수행"
- "~환경 구축 및 파일럿 실험 수행"
- "~기반 프로토타입 구현"

**2차년도**: 고도화·통합·실험 중심 표현
- "~알고리즘 고도화 및 실물 로봇 적용"
- "~모듈 통합 및 성능 정량 평가 수행"
- "~조건 확장 및 robust성 검증 수행"

**3차년도 이후**: 완성·실증·성과화 중심 표현
- "통합 시스템 최종 성능 검증 및 최적화 완료"
- "~실증 실험 수행 및 결과 분석 완료"
- "특허 출원 및 기술이전 패키지 준비 완료"

## 4. 기대 성과물 작성 기준

### 성과물 유형 및 표기

| 성과물 유형 | 표기 예시 |
|-------------|-----------|
| 소프트웨어·코드 | ○○ 알고리즘 코드 (GitHub 공개) |
| 하드웨어·장치 | ○○ 프로토타입 시스템 (1식) |
| 데이터셋 | ○○ 실험 데이터셋 (○○ 샘플 이상) |
| 보고서·문서 | ○○ 설계 보고서, ○○ 검증 보고서 |
| 논문 | SCI(E)급 학술지 논문 (○편) |
| 특허 | 국내 특허 출원 (○건) |
| 기술이전 | ○○ 기술이전 패키지 |

### 연차별 성과물 배분 원칙

- 1차년도: 설계 보고서, 초기 코드·모듈, 파일럿 데이터셋
- 2차년도: 고도화 모듈, 실험 보고서, 논문 투고 (국내외)
- 3차년도: 완성 시스템, SCI 논문, 특허 출원, 기술이전 패키지

## 5. 목표 달성 지표 표 작성 기준

### 지표 선정 원칙

- 각 세부목표당 2~4개의 정량 지표 설정함
- 이전 연차 대비 목표치를 점진적으로 높임 (예: 1차 75% → 2차 85% → 3차 95%)
- 측정 방법을 구체적으로 명시함 (실험 조건, 데이터셋 등)

### 지표 표 작성 예시

```
| 세부목표 | 평가 항목 | 1차년도 | 2차년도 | 3차년도 | 측정 방법 |
|----------|-----------|---------|---------|---------|-----------|
| 접촉력 제어 | 제어 오차 | ±1.0 N | ±0.7 N | ±0.5 N | 팬텀 실험 |
| 스캔 경로 | 장기 획득률 | 75% | 85% | 90% | 팬텀 실험 |
| 영상 분석 | Dice 계수 | 0.78 | 0.83 | 0.85 | 검증 데이터셋 |
```

## 6. 연차별 연구내용 체크리스트

연차별 연구내용 작성 완료 후 아래 항목을 점검함:

- [ ] 각 연차 연구내용이 해당 세부목표와 명확하게 연계됨
- [ ] 연차 간 연구 내용이 점진적으로 심화·발전하는 구조임
- [ ] 1차년도에 시뮬레이션/이론 검증이 포함됨
- [ ] 최종 연차에 실증 실험 및 성과물 완성 내용이 포함됨
- [ ] 모든 문장이 개조식(`~함`, `~됨`, `~임`)으로 종결됨
- [ ] 각 연차 기대 성과물 목록이 명시됨
- [ ] 정량 달성 지표 표가 포함됨
- [ ] 논문·특허 성과계획이 연차별로 분산되어 있음
