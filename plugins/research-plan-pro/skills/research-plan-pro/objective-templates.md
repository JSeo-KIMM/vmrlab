# 전체 연구목표 및 세부 개발목표 작성 템플릿

정부 제출용 연구개발계획서의 전체 연구목표 및 세부 개발목표 작성에 사용하는 표준 템플릿임.
모든 문장은 `writing-style.md`의 개조식 문체 규칙을 준수함.

---

## 1. 전체 연구목표 템플릿

### 구조

```
## 전체 연구목표

**[연구목표 제목]**: [명사형 종결 — ~의 개발 / ~기술 확보 / ~시스템 구축]

[목적 문장 1]: 본 연구는 ~을 위한 ~의 개발을 목표로 함.
[목적 문장 2]: ~기술을 핵심 요소로 활용하여 ~문제를 해결하고, ~효과를 달성하고자 함.
[기대효과]: ~분야에서 ~을 가능하게 함으로써 ~파급효과를 창출할 것으로 기대됨.
```

### 작성 기준

- 제목은 "~을 위한 ~의 개발/연구" 형식으로 간결하게 명명함
- 본문은 3~4문장 이내로 기술함
- 연구의 사회적·산업적 필요성을 1문장으로 포함함
- 핵심 기술 요소를 명시함
- 최종 기대효과를 명사형으로 종결함

### 예시

```
## 전체 연구목표

**로봇 기반 자율 초음파 진단 시스템 개발**

본 연구는 숙련 기사 의존 없이 자율적으로 초음파 검사를 수행하는 로봇 시스템 개발을 목표로 함.
힘 제어 기반 프로브 접촉 기술, 강화학습 기반 스캔 경로 계획 알고리즘, 딥러닝 기반 실시간 영상 분석 기술을 통합하여 의료 취약지에서도 표준화된 초음파 진단 서비스 제공 기반 마련을 목적으로 함.
본 시스템을 통해 원격·오지 지역의 의료 접근성 향상 및 초음파 검사 자동화 핵심 기술 확보가 기대됨.
```

## 2. 세부 개발목표 템플릿

### 전체 구조

```
## 세부 개발목표

| 번호 | 세부목표명 | 핵심 내용 | 정량 목표 |
|------|-----------|-----------|-----------|
| 1 | [명사형] | [1줄 요약] | [수치 기준] |
| 2 | ... | ... | ... |

### 세부목표 1: [목표명 — 명사형 종결]

- **개요**: [연구 필요성 및 핵심 접근 방식을 1~2문장으로 기술함]
- **핵심 달성 내용**:
  - [기술/결과물 1]
  - [기술/결과물 2]
  - [기술/결과물 3]
- **정량적 목표**:
  - [지표 1]: [수치 기준] ([측정 방법])
  - [지표 2]: [수치 기준] ([측정 방법])
```

### 세부목표 작성 기준

**목표명 작성 규칙**
- 명사형 종결 필수: "~알고리즘 개발", "~시스템 구축", "~기술 확보", "~모듈 개발"
- 동사형 금지: "~을 개발한다", "~를 구축하는 것"

**SMART 원칙 적용**
- Specific: 기술 대상과 방법을 구체적으로 명시함
- Measurable: 정량 지표(수치, %, fps, ms 등)를 포함함
- Achievable: 연구기간 내 달성 가능한 수준으로 설정함
- Relevant: 전체 연구목표와 직결된 내용으로 구성함
- Time-bound: 달성 연차를 연차별 연구내용에서 명확히 연계함

**세부목표 개수 기준**
- 3년 과제: 3~4개
- 4년 과제: 4~5개
- 5년 과제: 5~6개

### 예시

```
### 세부목표 1: 초음파 프로브 접촉력 제어 기술 개발

- **개요**: 환자 체표면에 초음파 프로브를 안전하게 접촉·유지하기 위한 임피던스 제어(Impedance Control) 알고리즘 개발 및 실시간 힘-토크 피드백 제어 시스템 구현을 목표로 함.
- **핵심 달성 내용**:
  - 적응형 임피던스 제어 기반 접촉력 유지 알고리즘 개발
  - 실시간 힘-토크 피드백 제어 시스템 구축
  - 이상 접촉 감지 및 긴급 이탈(Emergency Retraction) 기능 구현
- **정량적 목표**:
  - 접촉력 제어 오차: **±0.5 N 이내** (팬텀 실험 측정 기준)
  - 긴급 이탈 반응 시간: **0.1초 이내** (이상 접촉 감지 후 기준)
  - 연속 운용 안정성: **30분 이상** 접촉력 유지 (±0.5 N 기준)
```

## 3. 세부목표 간 연계성 체크리스트

세부목표 작성 완료 후 아래 항목을 점검함:

- [ ] 각 세부목표는 전체 연구목표의 하위 구성 요소로 논리적으로 연결됨
- [ ] 세부목표 간 중복 내용이 없음
- [ ] 세부목표 달성 시 전체 연구목표가 자연스럽게 달성되는 구조임
- [ ] 모든 세부목표에 정량적 목표치가 포함됨
- [ ] 정량 목표치는 측정 방법이 명시됨
- [ ] 목표명이 명사형으로 종결됨
