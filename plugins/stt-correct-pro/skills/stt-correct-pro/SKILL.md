# STT Correct Pro

STT(음성→텍스트 변환) 결과물을 깔끔하게 교정하는 스킬이다.

음성 인식은 완벽하지 않다. 동음이의어 혼동, 띄어쓰기 오류, 전문 용어 오인식, 그리고 말할 때 자연스러운 "어...", "그..." 같은 군더더기가 그대로 텍스트에 남는다. 이 스킬은 그런 문제들을 체계적으로 잡아준다.

## 입력

- 텍스트 파일 (.md 또는 .txt)
- 한국어가 주 대상 (영어 혼용 가능)

## 교정 단계

아래 순서대로 교정을 진행한다.

### 1단계: 군더더기 제거

말할 때 습관적으로 나오는 표현을 제거한다:
- 간투사: "어...", "음...", "그...", "아...", "뭐...", "이제...", "그런...", "저런..."
- 반복: "그러니까 그러니까", "네네네"
- 무의미한 연결어: "뭐 그런 거", "이런 저런", "약간 좀"
- 말끝 흐림: "~인 것 같고요...", "~하거든요..." (문맥상 불필요한 경우)

주의: 인용이나 대화체에서 의도적으로 쓰인 간투사는 살려둔다.

### 2단계: 오탈자 교정

STT가 만들어내는 전형적인 오류를 잡는다:
- 띄어쓰기: "할수있다" → "할 수 있다"
- 맞춤법: "됬다" → "됐다", "안됀다" → "안 된다"
- 조사 오류: "을를" → "을/를" 중 맞는 것
- 숫자/단위: "삼십 프로" → "30%" (문맥에 따라)

### 3단계: 맥락 기반 단어 교정

STT가 발음이 비슷한 다른 단어로 잘못 인식한 경우를 잡는다. 이것이 이 스킬의 핵심이다.

- 문장 전체의 맥락을 보고, 해당 단어가 의미적으로 맞는지 판단한다
- 전문 분야 용어는 특히 주의한다 (STT가 일반 단어로 바꾸기 쉬움)
- 확신이 높은 경우에만 교정한다

### 4단계: 문장 다듬기

원문의 어투(구어체/문어체)를 유지하면서 읽기 쉽게 정리한다:
- 구어체 원문이면 구어체를 유지하되, 군더더기만 빠진 깔끔한 구어체로 다듬는다
- 문어체 원문이면 문어체로 정리한다
- 문장이 너무 길면 적절히 나눈다 (말할 때는 길게 이어도 자연스럽지만, 글에서는 읽기 어려움)

핵심: 발화자의 의도, 뉘앙스, 어투를 바꾸지 않는다. 내용을 삭제하거나 추가하지 않는다.

## 출력 형식

원본 파일의 내용을 교정된 텍스트로 직접 덮어쓴다. 교정 요약이나 변경 내역은 추가하지 않는다. 깔끔하게 교정된 본문만 남긴다.

## 주의사항

- **의미 보존**: 교정은 표현만 다듬는 것이다. 발화자의 의견, 주장, 감정을 바꾸지 않는다.
- **어투 보존**: 구어체면 구어체, 문어체면 문어체를 유지한다. 스타일을 강제로 바꾸지 않는다.
- **화자 구분**: 화자가 구분되어 있으면 (예: "김과장:", "A:") 그 구조를 유지한다.
- **전문 용어**: 특정 분야 문서라면 해당 분야의 용어 관행을 따른다.
