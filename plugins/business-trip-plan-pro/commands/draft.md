# KIMM 국외출장 계획서 작성 커맨드

## 실행 절차

### Step 1: 입력 파싱
`$ARGUMENTS`에서 다음을 추출한다:
- **출장 개요 입력**: 파일 경로(`.md`, `.txt`)이면 Read로 읽고, 아니면 텍스트 자체를 출장 개요로 간주. 인자가 비어 있으면 인터뷰로 시작.
- **옵션**: `--output=<경로>`, `--type=<학회|전시회|연구과제>`, `--md-only`

파일 경로로 보이는데 존재하지 않으면 사용자에게 확인 후 텍스트로 처리한다.

### Step 2: business-trip-drafter 에이전트 호출
`business-trip-drafter` 서브에이전트에게 아래를 전달한다:
- 출장 개요 본문 (파일 내용 또는 텍스트, 빈 값 가능)
- 입력 파일 경로 (있을 경우)
- 작업 폴더 경로 (입력 파일 폴더 또는 현재 작업 폴더 cwd)
- 출력 폴더 경로 (`--output` 또는 작업 폴더)
- 출장유형 (`--type` 지정 시 그대로, 없으면 에이전트가 질문)
- hwpx 생성 여부 (`--md-only`가 없으면 true)

### Step 3: 결과 안내
에이전트 완료 후:
1. 생성된 파일 절대경로 (마크다운 초안, hwpx, 이미지 PNG 목록)
2. 출장 핵심 요약 (행사명, 출장지, 출장기간, 동행자, 합계 예산)
3. 사용자가 직접 마무리할 항목 (예: "hwpx 양식의 이미지 자리에 PNG 끼워넣기", "예실대비표 캡처 첨부")

## 에이전트 전달 프롬프트

다음 내용을 business-trip-drafter 에이전트에게 전달한다:

```
KIMM 국외출장 계획서(별지 제2호)를 양식에 맞춰 작성해주세요.

[출장 개요 본문]:
(파일 내용 또는 텍스트 전체. 비어있을 수 있음)

[입력 파일]: 파싱된 파일 경로 (없으면 N/A)
[작업 폴더]: 필수 파일을 탐색하고 결과를 저장할 폴더
[출력 폴더]: 결정된 출력 폴더 경로
[출장유형]: 학회 | 전시회 | 연구과제 | (미정 — 질문할 것)
[hwpx 생성]: true | false

작업 절차:
1. 출장유형 확정 → 유형별 필수 파일을 작업 폴더에서 탐색, 없으면 사용자에게 요청
2. 행사 정보를 웹에서 조사 (행사 홈페이지, 개요, 일정)
3. 누락 정보는 AskUserQuestion으로 한 번에 최대 4개씩 질문
4. 6개 표준 항목으로 마크다운 초안 작성 → 사용자 검토
5. 행사/일정/인보이스 이미지를 PNG로 저장
6. 별지 제2호 hwpx 양식을 채워 새 hwpx 파일 생성
7. 결과 파일 경로와 후속 작업 안내
```
