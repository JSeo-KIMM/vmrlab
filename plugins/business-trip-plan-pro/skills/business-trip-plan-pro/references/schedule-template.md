# 출장일정 표 작성 패턴

2번 항목의 일자별 출장일정 표. 출국일~귀국일을 받아 하루당 한 행을 생성한다.

## 표 구조

별지 제2호 양식의 출장일정 표는 6열이다.

| 열 | 머리글 | 내용 |
|---|---|---|
| 0 | 월 일 (요일) | `6월 17일 (월)` — 요일 **반드시** 기재 |
| 1 | 출발지 | 출발 도시 (이동 없는 날은 `-`) |
| 2 | 도착지 | 도착 도시 |
| 3 | 방문기관 | 학회장/방문기관명 (이동일은 `-`) |
| 4 | 업무수행내용 | 그날 활동 |
| 5 | 면담예정자 (직위포함) | 면담자 (없으면 `-`) |

## 일자별 행 생성 규칙

출장기간 `출국일 ~ 귀국 도착일`을 받아 다음과 같이 행을 만든다.

| 날 | 출발지 | 도착지 | 방문기관 | 업무수행내용 |
|---|---|---|---|---|
| 출국일 | 인천 | 출장국/도시 | - | 출국 및 <도시>(출장지) 도착 |
| 행사일 | - | 출장국/도시 | <학회장/기관> | <행사명> 참석 / 분야별 연구동향 파악 (+발표일은 "및 연구성과 발표") |
| 귀국 항공 탑승일 | 출장국/도시 | 인천 | - | 입국 항공기 탑승 |
| 인천 도착일 | - | 인천 | - | 인천 도착 |

- 시차로 출국일과 도착일이 같을 수도, 탑승일과 도착일이 다를 수도 있다. **항공인보이스의 실제 날짜**를 따른다.
- 요일은 한글로 자동 표기 (`(월)`, `(화)` ...).
- 행사일의 업무수행내용은 4번 항목과 출장목적을 근거로, 날마다 다른 세부 분야를 배치한다 (examples 참조).

## 동행자가 있을 때

업무수행내용·면담예정자 칸에 **개인별 내용을 분리**해 적는다 (양식 `※ 2인 이상 동행 시 개인별 명시` 규칙).

- 마크다운: 한 셀 안에서 `<br><br>`로 사람별 블록을 구분.
- hwpx: `set-cell`의 `--text`에 `\n`(빈 줄 포함)으로 사람별 블록을 구분.

예 (동행자 2인):
```
업무수행내용 셀:
CARS 2024 학술대회 참석
  Surgical Robotics 최신 연구동향 파악

CARS 2024 학술대회 참석
  Diagnostic Workflow 최신 연구동향 파악

면담예정자 셀:
심성보

서준호
```

## hwpx 표에 적용

출장일정 표는 양식에 머리글 1행 + 데이터 1행(인천/인천)만 있다.
필요한 날 수만큼 `scripts/hwpx_fill.py expand-rows`로 행을 추가한 뒤 `set-cell`로 채운다.
자세한 절차는 `hwpx-output.md` 참조.
