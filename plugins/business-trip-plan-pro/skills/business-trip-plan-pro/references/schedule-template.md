# 출장일정 표 작성 패턴

2번 항목 `○ 출장일정(세부적으로)` 아래의 일자별 표. 출국일~귀국 도착일을 받아
하루당 한 묶음(이동일=1행, 행사일=동행 인원수만큼의 행)을 만든다.

## 표는 HTML `<table>`로 작성한다

이 표는 **반드시 HTML `<table>` 태그**로 작성한다. 마크다운 파이프(`|`) 표는
쓰지 않는다. 이유는 분명하다 — 출장일정 표는 셀 병합이 필수다:

- 이동일(출국·귀국)은 업무수행내용을 한 칸으로 넓게 써야 함 → `colspan`
- 동행자가 2인 이상인 행사일은 하루를 인원수만큼의 행으로 나누되,
  월일·출발지·도착지·방문기관·면담예정자는 하루에 하나로 묶어야 함 → `rowspan`

마크다운 표는 `colspan`/`rowspan`을 표현하지 못하므로, examples 폴더의
두 사례(`example1`, `example2`)처럼 HTML 표로 작성해야 양식과 동일한 모양이 된다.
초안 검토·hwpx 변환의 기준이 되는 표이므로 examples의 구조를 그대로 따른다.

## 표 구조 — 머리글

이 표는 **물리적으로 7열**이다. `업무수행내용` 칸이 항상 2열을 차지하기 때문이다
(`colspan="2"`). 머리글 `<th>`는 6개를 쓰되, 그중 `업무수행내용`에 **`colspan="2"`를
반드시** 붙인다. 머리글은 아래 블록을 **글자 그대로 복사**해서 쓴다 — 열을 빼거나
`colspan`을 생략하면 머리글이 6열이 되어 본문(7열)과 어긋나 표 전체가 깨진다.

```html
<table>
  <thead>
    <tr>
      <th>월 일<br>(요일)</th>
      <th>출발지</th>
      <th>도착지</th>
      <th>방문기관</th>
      <th colspan="2">업무수행내용</th>
      <th>면담예정자<br>(직위포함)</th>
    </tr>
  </thead>
  <tbody>
    <!-- 일자별 행 -->
  </tbody>
</table>
```

`업무수행내용`의 두 열(4·5열)과 `면담예정자`(6열)는 **서로 다른 칸**이다.
4열 = 활동 내용, 5열 = 그 활동의 담당자 이름, 6열 = 면담예정자.
면담예정자가 없어 6열이 전부 `-`가 되더라도 **6열은 그대로 둔다** —
담당자 이름을 6열(면담예정자)에 절대 넣지 않는다. examples 두 사례도 면담예정자가
모두 `-`지만 별도 열로 유지하고 있다. 이 표는 examples의 7열 구조가 정답이다.

| 열 | 머리글 | 내용 |
|---|---|---|
| 0 | 월 일 (요일) | `6월 17일<br>(월)` — 요일 **반드시** 기재 |
| 1 | 출발지 | 출발 도시 (이동 없는 날은 `-`) |
| 2 | 도착지 | 도착 도시 (`스페인/<br>바르셀로나`처럼 국가/도시) |
| 3 | 방문기관 | 학회장/방문기관명 (이동일은 `-`) |
| 4 | 업무수행내용 | 그날 활동. 동행 2인 이상이면 5열은 담당자 이름이 들어감 |
| 5 | (업무수행내용 — 담당자) | 동행 2인 이상일 때만 사용. 단독·이동일은 4열이 `colspan="2"` |
| 6 | 면담예정자 (직위포함) | 면담자 (없으면 `-`) |

## 행(`<tr>`) 만드는 3가지 경우

### 경우 A — 이동일 (출국 / 귀국 항공 탑승 / 인천 도착)

한 행으로 쓰고, 업무수행내용은 `colspan="2"`로 두 열을 합친다.

```html
<tr>
  <td>6월 17일<br>(월)</td>
  <td>인천</td>
  <td>스페인/<br>바르셀로나</td>
  <td>-</td>
  <td colspan="2">출국 및 바르셀로나(출장지) 도착</td>
  <td>-</td>
</tr>
```

이동일의 표준 업무수행내용:
- 출국일 : `출국 및 <도시>(출장지) 도착`
- 귀국 항공 탑승일 : `입국 항공기 탑승`
- 인천 도착일 : `인천 도착`

### 경우 B — 행사일, 동행자 2인 이상

하루를 **동행 인원수(N)만큼의 `<tr>`**로 나눈다.
- 첫 행: 월일·출발지·도착지·방문기관·면담예정자 셀에 `rowspan="N"`을 주고,
  업무수행내용 셀 + 담당자 이름 셀(각 1열)을 둔다.
- 둘째 행부터: 업무수행내용 셀 + 담당자 이름 셀, 두 개의 `<td>`만 쓴다
  (`rowspan` 셀은 첫 행이 차지하므로 다시 쓰지 않는다).

```html
<tr>
  <td rowspan="2">6월 18일<br>(화)</td>
  <td rowspan="2">-</td>
  <td rowspan="2">스페인/<br>바르셀로나</td>
  <td rowspan="2">Universitat<br>Pompeu<br>Fabra</td>
  <td>- CARS 2024 학술대회 참석<br>- Surgical Robotics and Instrumentation 최신 연구동향 파악</td>
  <td>심성보</td>
  <td rowspan="2">-</td>
</tr>
<tr>
  <td>- CARS 2024 학술대회 참석<br>- Diagnostic / Therapeutic Workflow 최신 연구동향 파악</td>
  <td>서준호</td>
</tr>
```

- 담당자 이름 셀에는 **이름만** 쓴다(직위 제외). 면담예정자 열과 헷갈리지 않게 함.
- 동행 3인이면 `rowspan="3"` + `<tr>` 3개. N명이면 항상 `rowspan="N"`.
- 양식 안내문 `※ 2인 이상 동행 시 개인별 업무수행 내용을 구체적으로 명시`를
  지키는 구조다 — 사람마다 다른 세부 분야를 배치한다.

### 경우 C — 행사일, 단독 출장

담당자를 나눌 필요가 없으므로 한 행으로 쓰고 업무수행내용을 `colspan="2"`로 합친다.

```html
<tr>
  <td>6월 18일<br>(화)</td>
  <td>-</td>
  <td>스페인/<br>바르셀로나</td>
  <td>Universitat<br>Pompeu<br>Fabra</td>
  <td colspan="2">- CARS 2024 학술대회 참석<br>- Surgical Robotics and Instrumentation 최신 연구동향 파악</td>
  <td>-</td>
</tr>
```

## 행별 `<td>` 개수 — 표 완성 후 반드시 확인

병합 때문에 행마다 `<td>` 개수가 다르다. 표를 다 만든 뒤 아래를 대조한다.

| 행 종류 | `<td>` 개수 | 구성 |
|---|---|---|
| 이동일 (경우 A) | 6개 | 월일 / 출발지 / 도착지 / 방문기관 / 업무내용(`colspan="2"`) / 면담예정자 |
| 단독 행사일 (경우 C) | 6개 | 월일 / 출발지 / 도착지 / 방문기관 / 업무내용(`colspan="2"`) / 면담예정자 |
| 행사일·동행 N인 — 첫 행 (경우 B) | 7개 | 월일(`rowspan="N"`) / 출발지(rs) / 도착지(rs) / 방문기관(rs) / 업무내용 / 담당자이름 / 면담예정자(rs) |
| 행사일·동행 N인 — 둘째 행부터 (경우 B) | 2개 | 업무내용 / 담당자이름 |

자주 하는 실수 — 아래는 모두 **틀린 표**다:
- 머리글에서 `업무수행내용`의 `colspan="2"`를 빠뜨림 → 머리글 6열, 본문 7열로 깨짐
- 담당자 이름을 면담예정자 열에 넣고 면담예정자 칸을 생략 → 6열 표가 됨
- 경우 B 첫 행에서 `rowspan` 4개(월일·출발지·도착지·방문기관)와 면담예정자 `rowspan`을 빠뜨림
- 경우 B 둘째 행부터 `<td>`를 2개보다 많이 씀 (rowspan 칸을 다시 쓰면 안 됨)

## 셀 내용 작성 규칙

- 칸 안 줄바꿈은 `<br>`로 한다. 활동이 여러 개면 `- ` 불릿 줄을 `<br>`로 잇는다.
- 도시·기관명이 길면 `<br>`로 적절히 끊는다 (`스페인/<br>바르셀로나`, `Universitat<br>Pompeu<br>Fabra`).
- 발표가 있는 날은 업무수행내용에 `및 연구성과 발표`를 붙인다.
- 행사일의 세부 분야는 4번 항목·출장목적을 근거로 날마다 다르게 배치한다(examples 참조).
- 들여쓰기는 2칸 단위로 맞춰 표를 읽기 쉽게 유지한다.

## 표 아래 안내문

표 바로 아래에 양식의 `※` 안내문 2줄을 **그대로** 둔다.

```
※ 2인 이상이 동행하는 경우는 개인별 업무수행 내용을 구체적으로 명시
※ 출장일정 「요일」 반드시 기재 (국외출장사전자체평가서의 출발일, 귀국일 등 휴무일 연계성 평가)
```

## 날짜 산정 메모

- 시차로 출국일과 도착일이 같을 수도, 탑승일과 도착일이 다를 수도 있다.
  **항공인보이스의 실제 날짜**를 따른다.
- 요일은 한글로 자동 표기 (`(월)`, `(화)` …).

## hwpx 표로 옮길 때

hwpx 출장일정 표는 이 HTML 표와 **똑같은 7열 병합 모양**으로 만든다 — 별지 제2호
양식의 6열 평면 표를 `build-schedule` 명령으로 7열 병합 표로 통째 교체한다.
HTML 표를 그대로 옮긴 `days[]` JSON을 만들어 넘기면 된다. 절차·JSON 형식은
`hwpx-output.md` Step 4 참조.

- 경우 A·C(이동일·단독 행사일) → JSON의 `work` 한 줄. 업무수행내용이 colSpan=2로 합쳐짐.
- 경우 B(동행 2인 이상 행사일) → JSON의 `persons` 배열. 그 날이 인원수만큼 행으로
  나뉘고 날짜·장소 칸이 rowSpan으로 묶인다 — HTML 표와 동일.
- 칸 안 줄바꿈은 HTML에서 `<br>`, JSON에서 `\n`.
