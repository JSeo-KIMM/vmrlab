# 행사 웹 조사 + 이미지 캡처

## 1. 행사 정보 조사

### 홈페이지 찾기
- 행사명 + 연도로 WebSearch (예: `MICCAI 2025 official site`, `CARS 2024 conference`).
- 공식 홈페이지 URL을 확보한다. 위키·뉴스·블로그가 아닌 **주최측 공식 사이트**를 우선한다.
- 못 찾으면 사용자에게 "행사 홈페이지 URL을 알려달라"고 요청한다.

### 정리할 행사 개요
홈페이지를 근거로 다음을 정리한다 (1번 행사소개 + 4번 작성 근거):
- 행사명(정식 명칭·약어), 회차
- 개최 일정 (시작일~종료일)
- 개최 장소 (기관/컨벤션센터, 도시, 국가)
- 행사 성격: 목적, 역사(설립연도·연혁), 주요 학술/전시 분야
- 본인 연구분야(의료로봇/로봇/자동화)와의 연관성

추측하지 않는다. 일정·장소가 불명확하면 사용자에게 확인한다.

## 2. 이미지 캡처 — PNG 저장 + 자리표시 방식

**모든 이미지는 출력 폴더의 `images/` 하위에 PNG로 저장한다.** hwpx 양식에는 직접 삽입하지 않고
라벨이 붙은 자리만 남긴다 (`hwpx-output.md` 참조). 사용자가 한글에서 직접 끼워넣는다.

### 2-1. 행사 홈페이지 대표 이미지 / 일정 페이지

**우선 헤드리스 스크린샷을 시도**한다:
```bash
python scripts/capture_web.py "<행사 홈페이지 URL>" "<출력폴더>/images/행사_홈페이지.png"
python scripts/capture_web.py "<일정 페이지 URL>" "<출력폴더>/images/행사_일정.png" --full-page
```
- 종료 코드 `2`(Playwright/Chromium 미설치)이면 **폴백**: WebSearch/WebFetch로 행사 공식
  배너·키비주얼 이미지 URL을 찾아 `curl`/Bash로 다운로드한다.
- 폴백도 실패하면 사용자에게 "행사 대표 이미지를 직접 저장해 달라"고 요청하고, 자리표시만 남긴다.

행사 일정 페이지가 별도로 있으면(`program`, `schedule`, `agenda` 경로) 함께 캡처한다.

### 2-2. 항공인보이스 → 이미지

```bash
python scripts/pdf_to_png.py "<항공인보이스.pdf>" "<출력폴더>/images/항공인보이스" --dpi 200
```
첨부 항목에 들어갈 이미지로 사용한다.

### 2-3. 논문 첫 페이지 (학회 유형)

```bash
python scripts/pdf_to_png.py "<논문.pdf>" "<출력폴더>/images/논문첫페이지" --pages 1 --dpi 200
```

## 3. 캡처 이미지와 본문 마커 매칭

마크다운 초안·hwpx 본문의 이미지 마커와 PNG 파일명을 일관되게 맞춘다.

| 본문 마커 | PNG 파일 |
|---|---|
| `<그림. 행사 홈페이지>` | `images/행사_홈페이지.png` |
| `<그림. 행사 일정>` | `images/행사_일정.png` |
| `<그림. 논문 첫 페이지>` | `images/논문첫페이지_p1.png` |
| `<첨부. 항공 인보이스>` | `images/항공인보이스_p1.png` (여러 장이면 _p2 ...) |
| `<첨부. 예실대비표 1/2>` | (사용자 수동 캡처 — 빈칸) |

Phase 7에서 hwpx를 채울 때, 각 마커 위치에 `[그림: images/행사_홈페이지.png 삽입]`처럼
파일 경로를 안내하는 셀/문단을 남긴다.
