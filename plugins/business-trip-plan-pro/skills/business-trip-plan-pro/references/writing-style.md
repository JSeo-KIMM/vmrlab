# 작성 문체 규칙 (사용자 고유 스타일)

기존 2개 국외출장 계획서(서준호/심성보 CARS 2024)에서 추출한 사용자 고유의 문체 규칙. **이 규칙을 어기면 톤이 달라져 사용자가 직접 다시 손봐야 한다.**

## 1. 종결어미

### 표준
- 평서 문장은 **"~함"** 또는 **"~음"**으로 종결
- 명사형 종결도 자주 사용

### 예시 (그대로 사용 가능)
- "...학술대회 참석 및 연구성과 발표"
- "...연례 학회임"
- "...영상 정보학 및 의료 정보학 분야에서 선도적인 역할을 해왔음"
- "...연구 개발의 초점을 맞춰옴"
- "...성공적으로 개최되었음"
- "...최신 연구 동향과 기술을 파악하고자 함"
- "...의견 청취와 토론이 가능한 학회임"
- "...연구 결과 및 방향에 대해 논의함"
- "...홍보 활동"
- "...활동 중임"

### 금지
- "~합니다", "~합니다." (X)
- "~이다.", "~한다." (X — 이 사용자는 평서체보다 명사형 ~함체를 압도적으로 선호)
- "~할 것이다" (X)

### 예외
- 양식 자체의 주석성 가이드는 그대로 ("기재함" 등)
- 학회 소개문은 한 문단의 풀어쓴 서술이 가능하지만 마지막은 ~함/~음으로 닫음

## 2. 불릿과 들여쓰기

### 1차 불릿: ○
출장계획서는 1차 불릿으로 **하이픈(-)이 아닌 ○ 기호**를 자주 사용.

```
○ 출장기간 : ...
○ 출장국 : ...
○ 동행자 : ...
```

### 2차 불릿: 하이픈 + 공백
○ 항목의 하위 세부는 하이픈으로:

```
학회개요
  - 기    간 : ...
  - 장    소 : ...
```

### 3차 들여쓰기 (계층 구조)
2차 하이픈 아래에 부연이 필요하면 들여쓰기 후 다시 하이픈:

```
 - 1차 불릿
  - 2차 부연
```

### 콜론 정렬
"기 간 :", "장 소 :", "발표시간 :" 등 키 라벨에서 글자 간 공백을 활용해 시각적으로 정렬하는 패턴이 있음. 마크다운에서는 자연스럽게 한 칸 띄움 정도로만 모방.

## 3. 항목 번호 체계

### 메인 6개 항목
```
1. 출장목적
2. 출장일정
3. 최근 3년간 국외출장 실적
4. 출장중 파악(수행)해야 할 내용
5. 출장예산
6. 연구관련 반출 예정 전산장비 및 자료 현황
```

### 서브 섹션
- 1번 항목 내부: `학회개요`, `발표논문개요`, `학회소개`(서브 헤더 형태, 번호 없음)
- 4번 항목 내부: `○` 블록 단위로 활동 구분
- 5번 항목 내부: `○ 지급계정`, `○ 소요경비` 두 블록

## 4. 명사형/약어 표기

### 한글-영문 혼용
영어 학회명/논문 제목/세션명은 영문 그대로:
- "CARS 2024 (Computer Assisted Radiology and Surgery)"
- "Stewart Platform based Tele-operated Robotic System"
- "CAR Poster Session 2"

### 도시·국가
한글로 표기하되 익숙하지 않은 도시는 영문 병기:
- "스페인 (바로셀로나)"
- "Universitat Pompeu Fabra, Campus del Poblenou, 바로셀로나, 스페인"

### 과제 표기
지급계정과 본문 모두 `[과제번호]` 형식:
- "[EG0740] 비대면 진단이 가능한 다자유도 원격 로봇 플랫폼 개발"
- "[NK250E] 로보틱 검체 채취 통합형 고속 정밀 현장진단 핵심기술 개발"

## 5. 학회 소개문 톤

학회/방문기관 소개는 **한 문단(3~6 문장)** 으로 풀어쓰되, 마지막 종결은 ~함/~음.

권장 구성:
1. 학회의 권위/위상 (1문장)
2. 역사/연혁 (1문장)
3. 협력 단체/네트워크 (1문장, 선택)
4. 최근 개최지 또는 본 회 주제 (1문장)
5. 본인 연구와의 연관성/참석 의의 (1문장)

예시 톤:
> "CARS 학회는 세계적 차원에서 현대 의학을 이끄는 주요 혁신 기술을 발표하고 논의하기 위한 권위있는 국제 과학자, 엔지니어, 의사 커뮤니티의 연례 학회임. 1983년에 설립된 CARS는 40년 이상 영상 정보학 및 의료 정보학 분야에서 선도적인 역할을 해왔으며 ... 의료 분야의 새로운 알고리즘과 시스템 및 그 응용 프로그램 연구를 다방면으로 논의할 수 있는 학회임."

## 6. 4번 항목 — 활동 단위 작성

각 활동은 `○` 블록으로 분리하고 다음 패턴을 따름:

1. 첫 줄: `○ <행사명> <활동 유형>`
2. 다음 줄에 빈 줄 후 한 단락 서술
3. (선택) 키워드/세션 나열을 한 단락 더 추가
4. (선택) 그림 placeholder

예시:
```
○ <행사명> 학술대회 참석

"[<과제번호>] <과제명>" 과제를 수행중임. <행사명>의 참석 및 연구성과 발표를
통해, [<과제번호>] 과제에서 개발하고 있는 ...의 완성도를 높이고, ...의 최신
연구 동향과 기술을 파악하고자 함. 특히, 본 학회는 ...에 집중되어 엔지니어뿐만
아니라 ...도 다수 참석함. ... 의견 청취와 토론이 가능한 학회임.

주요 학술 분야: A, B, C, D, 등 기술 전반에 대하여 연구개발 내용 발표 참석을
통하여 최신기술 동향 파악 및 분석하고자 함.
```

## 7. 그림/이미지 placeholder

본문에 그림이 들어갈 자리는 다음 형식의 마커로 표기:

```
<그림. 논문 첫 페이지>
<그림. CARS 2024 홈페이지>
<그림. CARS 2024 소개>
<그림. CARS 2024 학회 일정>
```

마크다운 파일에는 실제 이미지 대신 placeholder만 두고, 사용자가 hwpx로 변환할 때 실제 이미지를 붙여 넣음.

첨부 이미지(예실대비표, 항공 인보이스)도 동일하게 `<첨부. 예실대비표>`, `<첨부. 항공 인보이스>` 마커로 표기.

## 8. 도메인 톤

사용자 배경(KIMM 의료로봇연구실)에 따른 톤:
- 대상: 의료/산업 로보틱스, 기계/메카트로닉스 분야
- 자주 쓰이는 키워드: "원격 진단", "마스터-슬레이브", "Stewart Platform", "엔도스코프", "AI 기반 제어", "의료현장 적용", "의료진(MD)"

이 도메인이 아닌 출장(예: 일반 자동차 분야, 에너지)에서는 키워드만 도메인에 맞게 바꾸고, 톤·구조는 동일하게 유지.
