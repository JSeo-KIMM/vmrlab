# 사용자 인터뷰 프로토콜

출장 개요 입력이 6개 항목을 모두 채우기에 부족할 때, 사용자에게 적절히 질문하여 보완 정보를 수집하는 가이드.

## 핵심 원칙

1. **AskUserQuestion 사용**: 자유 텍스트 질문 대신 선택지 + 자유응답 가능한 도구 활용
2. **한 라운드 최대 4개 질문**: 인지 부담 최소화. 4개 초과면 라운드를 나눔
3. **최대 2~3 라운드**: 무한 인터뷰는 사용자를 지치게 함. 핵심만 묻고 작성으로 진입
4. **추측 가능한 항목은 묻지 않음**: 본문에 단서가 있으면 그것을 활용
5. **WebSearch 우선**: 학회 일정/장소/URL은 사용자에게 묻기 전 WebSearch로 후보를 마련해서 확인

## 라운드 구성 가이드

### 라운드 1: 출장 핵심 4종
입력에 빠진 것만 골라 한 번에 최대 4개. 4개 모두 빠졌으면 한 번에 다 묻는다.

| 슬롯 | 질문 | 옵션 예시 |
|---|---|---|
| 행사명 | 행사명 또는 학회명이 무엇입니까? | "CARS 2025" / "MICCAI 2025" / "ICRA 2025" / 자유 입력 |
| 출장지 | 출장 도시와 국가, 방문기관은 어디입니까? | 자유 입력 (예: "Daejeon, Korea / KAIST") |
| 출장기간 | 출장 출국일과 귀국일은 언제입니까? | 자유 입력 (예: "2025-09-22 ~ 2025-09-28") |
| 신청자 | 신청자 소속/직급/성명은? | "의료로봇연구실 / 책임연구원 / 서준호" 등 자유 입력 |

### 라운드 2: 출장 부가정보
| 슬롯 | 질문 |
|---|---|
| 동행자 | 동행자가 있습니까? 있다면 직급/성명을 알려주세요. (없으면 "단독 출장") |
| 발표논문 | 발표 논문이 있습니까? 있다면 제목/저자/발표시간을 알려주세요. |
| 지급계정 | 지급계정(과제번호 + 과제명)을 알려주세요. |
| 부가활동 | 학회 외 부가 활동(이사회 참석, 차년도 학회 홍보, 협력기관 미팅 등)이 있습니까? |

### 라운드 3: 예산/실적/반출
| 슬롯 | 질문 |
|---|---|
| 등급지 | 출장 국가/도시의 여비 등급지(가/나/다)를 아십니까? (모르면 자동 추론) |
| 왕복교통비 | 왕복 항공권 실제 금액(원화)을 알려주세요. (인보이스 기준) |
| 환율 | 적용 환율이 있습니까? (없으면 작성 시점 환율 자동 사용) |
| 최근3년실적 | 최근 3년간 국외출장 실적이 있습니까? 있다면 (기간 / 국가-도시 / 목적). 없으면 "해당사항 없음" |
| 반출장비 | 노트북/USB/외장하드/인쇄물 중 반출 항목이 있습니까? |

## 항목별 질문 트리거

### 1번 출장목적 — 학회 소개문

학회가 유명하고 WebSearch로 정보 확보 가능하면 사용자에게 묻지 않고 자동 작성. 단, 본인의 연구와의 연관성은 사용자 입력 또는 입력 텍스트에서 추론.

### 2번 출장일정 — 일자별 활동

행사 기간(예: 4일)이 정해지면 자동으로 일자별 행을 생성. 동행자가 있으면 한 행 안에 동행자별 활동 분리.

세부 활동 키워드를 사용자에게 묻되, 추측 가능하면 묻지 않음:
- "각 일자별 출장자가 집중할 키워드(세션/주제)가 있습니까?" (선택 — 없으면 학회 일반 키워드로 채움)

### 3번 최근 3년 실적

라운드 3에 포함. 있으면 기간/국가/목적 1줄씩, 없으면 "해당사항 없음"으로 표기.

### 4번 파악/수행 내용

`동행자별 세부역할`은 동행자 정보가 있을 때만 묻는다. 활동 단위는 `학술대회 참석`, `학술대회 논문 발표`, `(있으면) 부가활동`.

질문:
- "본인이 수행할 핵심 기술 동향 파악 키워드는 무엇입니까?" (자유 입력)
- "동행자가 있다면 동행자가 집중할 분야는 무엇입니까?" (자유 입력)

### 5번 예산

라운드 3에 포함. `--no-budget`이면 빈 표만 남기고 사용자가 후속 채울 수 있도록 안내.

### 6번 반출 장비

라운드 3에 포함. 모두 "(  )"로 비워두는 게 기본값.

## WebSearch 활용 가이드

다음 정보는 사용자에게 묻기 전 WebSearch로 우선 조사:

| 정보 | 검색 쿼리 예시 |
|---|---|
| 학회 일정 | `"<행사명>" <연도> dates venue` |
| 학회 장소 | `"<행사명>" <연도> location university` |
| 환율 | `USD KRW exchange rate <YYYY>-<MM>-<DD>` |
| 등급지 | `KIMM 출장 여비 <국가> 등급지` (사내 자료 — 어려우면 사용자에게 확인) |

검색 결과를 사용자에게 제시하고 "이 내용 맞습니까?" 형식으로 확인.

## 추측 금지 항목

다음 항목은 절대 추측해서 채우지 않는다:
- 항공편명, 좌석 등급
- 호텔명
- 동행자 이름 / 직급
- 지급계정 번호
- 정확한 환율 (입력 또는 검색 확인 필요)
- 사용자의 최근 3년 출장 이력

이 항목들은 입력에 없거나 사용자가 모르면 placeholder(`[기재 필요]`)로 두고 작성 후 보고에서 명시한다.
