# 필수 파일 점검 + 인터뷰 전략

## 1단계: 출장유형 확정

`--type`이 없으면 AskUserQuestion으로 묻는다.

| 옵션 | 설명 |
|---|---|
| 학회 | 논문 발표·참석 목적 학술대회 |
| 전시회 | 산업·기술 전시회 참관/참가 |
| 연구과제 관련 | 연구과제 수행 관련 출장(킥오프, 협력기관 방문 등) |

## 2단계: 필수 파일 점검

작업 폴더를 Glob으로 스캔한다 (`*.pdf`, `*.hwpx`, `*.docx`, `*.md`, `*.txt`, `*.pptx`).
파일명에 아래 키워드가 포함되는지로 식별한다.

### 유형별 필수 파일

| 파일 | 학회 | 전시회 | 연구과제 | 식별 키워드 (파일명) |
|---|:--:|:--:|:--:|---|
| 논문 파일 | 필수 | — | — | `논문`, `paper`, 영문 논문 제목 |
| 연구과제관련 파일 | — | — | 필수 | `과제`, `연구과제`, 과제번호 |
| 항공인보이스 파일 | 필수 | 필수 | 필수 | `인보이스`, `invoice`, `항공`, `e-ticket` |
| 내용참고 파일 | 필수 | 필수 | 필수 | `내용참고`, `참고`, `메모` |

### 양식·여비표 파일 (모든 유형)

| 파일 | 작업 폴더에서 찾기 | 폴백 |
|---|---|---|
| `[별지 제2호] 국외출장 계획서.hwpx` | 키워드 `별지`, `국외출장 계획서`, `.hwpx` | 플러그인 `assets/[별지 제2호] 국외출장 계획서.hwpx` |
| `[별표 제2-1호] 해외출장 여비 정액표.pdf` | 키워드 `여비`, `정액표` | 플러그인 `assets/[별표 제2-1호] 해외출장 여비 정액표.pdf` |

### 내용참고 파일 검증

내용참고 파일을 Read하여 **출장예산 지급계정과 계정명**이 들어 있는지 확인한다.
- 예: `EG0740 / 비대면 진단이 가능한 다자유도 원격 로봇 플랫폼 개발`
- 없으면 사용자에게 "내용참고 파일에 지급계정(과제번호)과 계정명을 추가해 달라"고 요청한다.

### 누락 처리 규칙

- 필수 파일이 하나라도 없으면 **작성을 멈추고** 어떤 파일이 어떤 이유로 필요한지 구체적으로 알린다.
- 사용자가 파일을 작업 폴더에 넣었다고 하면 다시 스캔한다.
- 모든 필수 파일이 확보되어야 Phase 2(웹 조사)로 진입한다.

## 3단계: 항목별 충분성 점검

| 항목 | 점검 기준 |
|---|---|
| 헤더 | 제출일자, 신청자(기본값 사용 가능) |
| 1. 출장목적 | 행사명·개요 확보? 유형별 블록(논문/연구분야/과제연관) 자료 확보? |
| 2. 출장일정 | 출국·귀국일(항공인보이스), 출장국, 동행자 확보? |
| 3. 최근 3년 실적 | 사용자가 실적을 제공했는가? |
| 4. 파악·수행 내용 | 수행 과제, 발표/부가활동 확보? |
| 5. 출장예산 | 지급계정(내용참고), 등급지, 환율, 왕복교통비(인보이스) 확보? |

## 4단계: AskUserQuestion 인터뷰

원칙:
- 한 라운드당 최대 4개 질문, 최대 2~3 라운드.
- 웹 조사·자료·기본값으로 알 수 있는 항목은 묻지 않는다.
- 행사 일정·장소가 모호하면 WebSearch로 먼저 조사하고, 결과를 사용자에게 확인받는다.

**반드시 묻는 항목** (자료로 확인 불가할 때):
1. 동행자 (직급/성명, 없으면 "단독 출장")
2. 최근 3년 국외출장 실적
3. 부가 활동 (이사회 참석, 차기 행사 홍보 등)
4. 항공좌석 등급·왕복교통비가 인보이스에서 안 읽히면 사용자 확인

웹 조사로 행사 홈페이지를 못 찾으면 사용자에게 URL을 요청한다.
