## 헤더

- `제출일자` : 계획서 작성/제출일. 형식 `2024. 5. 16.` (월·일 앞 0 생략).
- `신청자` 표 : 소속 / 직급 / 성명. 기본값 = 로봇응용연구실 / 책임연구원 / 서준호.

## 1. 출장목적

`○ <행사명> 학회 참석 및 연구성과 발표` 형태의 한 줄 요약으로 시작한 뒤, 3블록 구성:

**학회개요** (모든 유형 공통)
```
학회개요
  - 기    간 : 2024. 06. 18.(화). ～ 2024. 06. 21(금)
  - 장    소 : <개최 장소(기관/캠퍼스), 도시, 국가>
```

**유형별 두 번째 블록**
- **학회**: `발표논문개요` — 발표시간, 논문제목, 논문저자. 작업 폴더의 논문 파일에서 제목·저자를 그대로 추출 (지어내지 않음).
- **전시회**: `참가목적` — 본인 연구분야(의료로봇/로봇/자동화 등)와 전시회의 연관성을 2~4문장으로 기술.
- **연구과제**: `과제연관개요` — 연구과제관련 파일을 근거로 해당 행사와 과제의 연관성을 기술.

**행사소개** (모든 유형 공통)
- `행사소개 : <행사의 목적·역사·성격·연구 연관성을 한 단락으로>` — Phase 2 웹 조사 결과를 근거로 작성.

## 2. 출장일정

```
○ 출장기간 : 2024. 06. 17. ～ 2024. 06. 23. (5박 7일간)
○ 출장국 : 스페인 (바로셀로나)
○ 동행자 : 심성보 선임연구원        ← 없으면 "단독 출장"
○ 출장일정(세부적으로)
```
- 출장기간은 **행사 일정과 항공인보이스의 실제 출국·귀국일을 함께 보고 산정**한다.
- 일자별 표는 `schedule-template.md` 참조. 표 아래 `※` 안내문 2줄은 양식 그대로 유지.

## 3. 최근 3년간 국외출장 실적

| 출 장 기 간 | 출장국가 및 출장지역 | 출 장 목 적 |
|---|---|---|
| 2023.05.29.∼2023.06.03 | 런던/ 영국 | ICRA 2023 참석 및 성과발표 |

- 실적 정보는 사용자에게 묻는다. 없으면 표 대신 `(해당사항 없음)`으로 표기.

## 4. 출장중 파악(수행)해야 할 내용

행사 정보를 좀 더 자세히 기술하고, 연구과제/발표 활동과 행사를 연관지어 여러 단락으로 작성한다.

- 동행자가 있으면 `출장 동행자 이름 / 세부 역할` 표를 먼저 둔다.
- `○ <행사명> 학술대회 참석` — 수행 과제와 행사의 연관성, 주요 학술 분야 나열.
- `○ <행사명> 논문 발표` (학회) — 발표 논문의 핵심 내용.
- 부가 활동(이사회 참석, 차기 학회 홍보 등)이 있으면 `○` 블록을 추가.
- 이미지 자리는 본문에 마커로 표기: `<그림. 행사 홈페이지>`, `<그림. 행사 일정>`, `<그림. 논문 첫 페이지>` 등.

## 5. 출장예산

```
○ 지급계정 ( <과제번호> <과제명> )       ← 내용참고 파일에서 추출
○ 소요경비
```
소요경비 표: 왕복교통비 / 일비 / 식비 / 숙박비 / 합계. 산식·계산은 `budget-calculator.md` 참조.
표 아래에 등급지·환율·근거를 명시:
```
<출장국>: 국가 및 도시별 등급 기준 <가|나|다|라> 등급지
환율: $1=1,368.50원 (YYYY년 MM월 DD일 기준)
<별표 제2-1호> 해외출장 여비 정액표 기준
```

## 6. 연구관련 반출 예정 전산장비 및 자료 현황

- **이 항목은 수정하지 않는다.** 별지 제2호 양식의 기본 표·문구를 그대로 둔다.
