# KIMM 국외출장 계획서(별지 2) 양식 구조

## 전체 골격

문서 최상단에 양식 식별자와 제목, 제출일자, 신청자 정보가 오고, 그 아래 6개 메인 항목이 순서대로 배치됨. **항목 번호와 제목은 절대 변경하지 않음.**

```
[별지 2]

                 국외출장 계획서

제출일자 : YYYY. M. D.

<신  청  자>
| 소 속 | 직 급 | 성 명 |
| ----- | ----- | ----- |
| (소속) | (직급) | (성명) |

                 국외출장계획서

1. 출장목적
2. 출장일정
3. 최근 3년간 국외출장 실적
4. 출장중 파악(수행)해야 할 내용
5. 출장예산
6. 연구관련 반출 예정 전산장비 및 자료 현황

첨부 : 1. 관련 계정 예실대비표.
       2. 항공 인보이스.
```

> 헤더 블록(`[별지 2]`, `국외출장 계획서`, `제출일자`, `신청자` 표)은 그대로 유지하고, 본문 직전에 두 번째 제목인 `국외출장계획서`를 한 번 더 두는 양식 패턴을 따른다.

## 항목별 작성 규칙

### 1. 출장목적

다음 3개 블록을 ○ 항목 + 하위 하이픈 불릿으로 구성한다.

```
○ <행사명> (영문 풀이름) 학회 참석 및 연구성과 발표

학회개요
  - 기    간 : YYYY. MM. DD.(요일). ～ YYYY. MM. DD(요일)
  - 장    소 : <방문기관>, <캠퍼스/주소>, <도시>, <국가>

발표논문개요
  - 발표시간 : YYYY. M. D.(요일) HH:MM–HH:MM. (<세션명>)
  - 논문제목 : <논문 제목>
  - 논문저자 : <저자 콤마 구분>

학회소개 : <한 문단 — 학회의 권위, 역사, 주제, 본인 연구와의 연관성>
```

- 발표가 없는 출장이면 `발표논문개요` 블록은 생략 가능.
- 학회가 아닌 방문(공장 견학, 협력 미팅 등)이면 `학회개요` 대신 `방문개요`로 라벨만 바꾸고 동일 형식 유지.

### 2. 출장일정

상단 4개 ○ 라인 + 하단 일정 표.

```
○ 출장기간 : YYYY. MM. DD. ～ YYYY. MM. DD. (N박 M일간)
○ 출장국 : <국가> (<도시>)
○ 동행자 : <동행자 직급/성명> (없으면 "단독 출장")
○ 출장일정(세부적으로)
```

일정 표(반드시 다음 6개 컬럼):

```
| 월 일 (요일) | 출발지 | 도착지 | 방문기관 | 업무수행내용 | 면담예정자(직위포함) |
```

행 작성 규칙:
- 첫째 행: 출국일 (인천 → 출장지 도시), 업무수행내용은 `출국 및 <도시>(출장지) 도착`, 면담예정자는 `-`
- 마지막에서 두 번째 행: 귀국 항공 탑승일 (출장지 → 인천), 업무수행내용은 `입국 항공기 탑승`
- 마지막 행: 인천 도착일 (- → 인천), 업무수행내용은 `인천 도착`
- 중간 행: 행사일별 활동. 동행자가 있으면 한 행 내부에 업무수행내용을 동행자별로 줄바꿈하여 분리하고 면담예정자 칸에 동행자 이름을 명시

표 아래 주의사항(원본 양식 그대로 유지):

```
※ 2인 이상이 동행하는 경우는 개인별 업무수행 내용을 구체적으로 명시
※ 출장일정 「요일」 반드시 기재 (국외출장사전자체평가서의 출발일, 귀국일 등 휴무일 연계성 평가)
```

### 3. 최근 3년간 국외출장 실적

표 또는 "(해당사항 없음)".

```
| 출 장 기 간 | 출장국가 및 출장지역 | 출 장 목 적 |
| YYYY.MM.DD.∼YYYY.MM.DD | <도시>/<국가> | <목적> |
```

실적이 없으면:

```
3. 최근 3년간 국외출장 실적

(해당사항 없음)
```

### 4. 출장중 파악(수행)해야 할 내용

상단에 동행자별 세부역할 표:

```
| 출장 동행자 이름 | 세부 역할 |
| <성명1> | <역할 한 줄 요약> |
| <성명2> | <역할 한 줄 요약> |
```

그 아래 활동별로 `○` 블록:

```
○ <행사명> 학술대회 참석
  "[<지급계정 과제번호>] <과제명>" 과제를 수행중임.
  <행사명>의 참석 및 연구성과 발표를 통해, [<과제번호>] 과제에서 개발하고 있는
  ...의 완성도를 높이고, ...의 최신 연구 동향과 기술을 파악하고자 함.
  특히, 본 학회는 ...에 집중되어 ... 의견 청취와 토론이 가능한 학회임.

  주요 학술 분야: <쉼표 구분 키워드 나열>, 등 기술 전반에 대하여
  연구개발 내용 발표 참석을 통하여 최신기술 동향 파악 및 분석하고자 함.

○ <행사명> 학술대회 논문 발표
  [<과제번호>] 과제를 통해 개발한 ...에 대해 발표하고 연구 결과 및 방향에 대해 논의함.

  논문 제목: <논문 제목>

  <그림. 논문 첫 페이지>
  <그림. 행사 홈페이지>
  <그림. 행사 소개>
  <그림. 행사 일정>
```

본인이 추가로 수행하는 부가 활동(예: 협회 이사회 참석, 차년도 학회 홍보 등)이 있으면 추가 `○` 블록으로 작성:

```
○ <부가 활동명>
  ...
```

### 5. 출장예산

```
○ 지급계정 ( <과제번호> <과제명> )
○ 소요경비

| 항목 | 산식 | 금액 |
| ----- | ----- | ----- |
| 왕복교통비 | <항공좌석 등급> | X,XXX,XXX원 |
| 일 비 | (일액) * (일수) | (XXX,XXX 원) |
| 식 비 | (일액) * (일수) | (XXX,XXX 원) |
| 숙 박 비 | (일액) * (일수) | (X,XXX,XXX 원) |
| 합 계 | | X,XXX,XXX 원 |

<국가>: 국가 및 도시별 등급 기준 <등급> 등급지
환율: $1=X,XXX.XX원 (YYYY년 MM월 DD일 기준)
<별표 제2-1호> 해외출장 여비 정액표 기준
```

- 일비/식비/숙박비 단가는 `budget-calculator.md`의 등급지 표를 따름
- 일수는 출장기간(N박 M일)을 기준으로 결정 — 보통 일비/식비는 행사 일수, 숙박비는 (일수-1)
- 합계는 모든 항목 원화 합산

### 6. 연구관련 반출 예정 전산장비 및 자료 현황

체크박스 표 그대로 유지(반출 항목이 있으면 `(√)`로 표기):

```
| 구 분 | ※ 해당란 체크(√) | 반출 목적 | 반출 자료내용 (내장자료 또는 인쇄물 내용) |
| ㆍ노트북/테블릿PC | ( ) | - | - |
| ㆍUSB | ( ) | | |
| ㆍ외장하드디스크 | ( ) | | |
| ㆍ 기타(내용기재) | | | |
| ㆍ인쇄물 (복사자료 등) | ( ) | - | - |

* 노트북 및 보조기억매체는 연구원에 등록된 것만 반출하여야 함.
* 노트북 반출시에는 「MIS-자산관리-물품반출/반입신청(내부)」에 신고하여야 함.
```

## 첨부 안내

본문 마지막에:

```
첨부 : 1. 관련 계정 예실대비표.
       2. 항공 인보이스.

1. <과제번호> 과제 당해연도 예실대비표
   (이미지 또는 표 첨부)

2. 항공편 인보이스
   (이미지 첨부)
```

첨부 이미지는 마크다운 파일 자체에는 포함하지 않고 `<첨부. 예실대비표>`, `<첨부. 항공 인보이스>` 같은 placeholder만 두고 사용자가 .hwpx 변환 시 직접 붙여 넣도록 안내.
