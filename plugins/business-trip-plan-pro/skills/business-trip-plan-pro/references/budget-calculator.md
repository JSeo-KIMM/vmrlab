# 출장 예산 자동 계산 가이드

기존 2개 출장계획서(서준호/심성보)에서 추출한 예산 계산 패턴. 「공무원 여비 규정」 별표 제2-1호(해외출장 여비 정액표)에 따른 등급지별 단가를 사용한다.

## 등급지 분류 (참고)

| 등급 | 대표 도시 |
|---|---|
| 특 | 도쿄, 뉴욕, 런던, 파리 일부 도시 |
| 가 | 미국 주요 도시, 캐나다, 영국, 호주, 중동 일부 |
| 나 | 유럽 주요국(독일, 프랑스, 이탈리아, 스페인 등), 일본 일부 |
| 다 | 동남아, 중국, 동유럽 등 |

> 정확한 등급지는 사내 「국외여비 등급지 분류표」를 따라야 함. 모호하면 사용자에게 확인.

## 등급지별 일액 (USD 기준, 참고)

> 아래는 사용자 기존 사례(2024년 5월 기준 스페인 = 나 등급지)에서 역산한 값. **정확한 단가는 KIMM 사내 「별표 제2-1호 해외출장 여비 정액표」 참조 필수.**

| 등급 | 일비(USD/일) | 식비(USD/일) | 숙박비(USD/박) |
|---|---|---|---|
| 특 | 50 | 100 | 200 (실비, 상한 제도 가능) |
| 가 | 40 | 90 | 180 |
| 나 (책임연구원) | 35 | 78 | 160 |
| 나 (선임연구원) | 30 | 59 | 137 |
| 다 (책임연구원) | 30 | 60 | 120 |
| 다 (선임연구원) | 25 | 50 | 100 |

> **직급별 차등**: 동일 등급지라도 책임연구원/선임연구원/연구원에 따라 단가가 다름. 사용자 직급을 반드시 확인.

## 사용자 기존 사례 (2024.06 스페인 바로셀로나 / 나 등급지)

### 책임연구원 (서준호)
```
일 비   : 35 USD/일 × 6일 = 210 USD ≈ 287,385 원
식 비   : 78 USD/일 × 6일 = 468 USD ≈ 640,458 원
숙 박 비 : 160 USD/박 × 5박 = 800 USD ≈ 1,094,800 원
환율 : $1 = 1,368.50원 (2024년 05월 13일 기준)
```

### 선임연구원 (심성보)
```
일 비   : 30 USD/일 × 6일 = 180 USD ≈ 246,330 원
식 비   : 59 USD/일 × 6일 = 354 USD ≈ 484,449 원
숙 박 비 : 137 USD/박 × 5박 = 685 USD ≈ 937,423 원
환율 : $1 = 1,368.50원 (2024년 05월 13일 기준)
```

> 기존 사례는 5박 7일 출장에서 일비/식비를 6일분(귀국 항공 탑승일까지)으로, 숙박비는 5박분으로 계산함.

## 일수 산정 규칙

### N박 M일 → 일비/식비/숙박비

| 항목 | 일수 |
|---|---|
| 일비 | 출국일부터 귀국 항공 탑승일까지 (= 출장 일수 - 1, 인천 도착일 제외) |
| 식비 | 출국일부터 귀국 항공 탑승일까지 (= 일비와 동일) |
| 숙박비 | 박 수 (= 출장 일수 - 2) |

> 5박 7일이면: 일비 = 6일, 식비 = 6일, 숙박비 = 5박 (사용자 기존 사례 기준)

> 4박 6일이면: 일비 = 5일, 식비 = 5일, 숙박비 = 4박

> 단독 출장이고 인천 도착일이 출국일과 같은 날이면 일수 산정이 달라짐 — 사용자 확인 필요.

## 자동 계산 산식

```
일비_원화   = 일비_USD × 일수 × 환율
식비_원화   = 식비_USD × 일수 × 환율
숙박비_원화 = 숙박비_USD × 박수 × 환율
합계        = 왕복교통비 + 일비_원화 + 식비_원화 + 숙박비_원화
```

원화 환산 결과는 **원 단위까지 표기** (소수 절사 또는 반올림은 사용자 기존 사례에 맞춰 반올림 사용).

## 표 작성 형식 (출장계획서 5번 항목)

```
○ 지급계정 ( <과제번호> <과제명> )
○ 소요경비

| 항목      | 산식                | 금액              |
| --------- | ------------------- | ----------------- |
| 왕복교통비 | (항공좌석 등급: Economy) | 2,806,800원   |
| 일 비     | 35 * 6              | (287,385 원)     |
| 식 비     | 78 * 6              | (640,458 원)     |
| 숙 박 비  | 160 * 5             | (1,094,800 원)   |
| 합 계     |                     | 4,829,443 원     |

<국가>: 국가 및 도시별 등급 기준 <등급> 등급지
환율: $1 = 1,368.50원 (2024년 05월 13일 기준)
<별표 제2-1호> 해외출장 여비 정액표 기준
```

## 환율 적용

- 환율은 출장 신청일 또는 신청 직전 영업일 기준 매매기준율 사용
- WebSearch 또는 사용자 입력으로 확보
- 표기 형식: `$1 = X,XXX.XX원 (YYYY년 MM월 DD일 기준)`

## 왕복교통비

- 인보이스 실제 금액(원화)을 사용자에게 받음
- 자동 계산하지 않음 (항공권은 시기/노선별로 변동성이 큼)
- 좌석 등급 명시 필수: "(항공좌석 등급: Economy)"

## --no-budget 옵션

`--no-budget`이 켜져 있으면 위 표를 다음과 같이 빈 양식만 두고, 사용자가 후속 작성하도록 안내:

```
○ 지급계정 ( [기재 필요] )
○ 소요경비

| 항목      | 산식                | 금액         |
| --------- | ------------------- | ------------ |
| 왕복교통비 | (항공좌석 등급: ____) | [기재 필요]  |
| 일 비     | __ * __             | [기재 필요]  |
| 식 비     | __ * __             | [기재 필요]  |
| 숙 박 비  | __ * __             | [기재 필요]  |
| 합 계     |                     | [기재 필요]  |
```

## 등급지 자동 추론 (사용자가 모를 때)

WebSearch나 일반 지식으로 추정 가능한 경우 후보 1~2개를 사용자에게 제시:

- 미국 주요 도시(뉴욕, LA, 시카고, 보스턴, 샌프란시스코) → 가 등급지
- 일본 도쿄 → 특 등급지
- 일본 기타 도시(오사카, 후쿠오카) → 가 또는 나
- 유럽 주요국(독일, 프랑스, 영국, 이탈리아, 스페인) → 나 등급지
- 동남아(싱가포르, 태국, 베트남) → 다 등급지
- 중국 주요 도시 → 다 등급지

**중요**: 등급지가 정확히 매핑되지 않으면 임의로 정하지 말고 사용자에게 확인을 받거나 placeholder로 표기.
