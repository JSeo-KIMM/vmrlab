# 출장예산 계산 (해외출장 여비 정액표 기준)

5번 출장예산 항목의 소요경비를 계산한다. 단가는 **반드시 작업 폴더/assets의 여비표
`[별표 제2-1호] 해외출장 여비 정액표.pdf`를 직접 읽어 확인**한다. 아래 표는 2025.8.27.
개정본 요약이며, 여비표 원본과 다르면 원본이 우선이다.

## 1. 직급별·등급별 정액 (단위: 미 달러)

| 구분 | 등급 | 일비 | 숙박비 | 식비 |
|---|---|--:|--:|--:|
| 임원 | 가 / 나 / 다 / 라 | 50 / 50 / 50 / 50 | 389 / 289 / 215 / 161 | 160 / 117 / 87 / 73 |
| (본)부장 이상 | 가 / 나 / 다 / 라 | 40 / 40 / 40 / 40 | 282 / 207 / 162 / 108 | 133 / 99 / 72 / 61 |
| **책임급** | 가 / 나 / 다 / 라 | **35 / 35 / 35 / 35** | **223 / 160 / 130 / 85** | **107 / 78 / 58 / 49** |
| 선임급 이하 | 가 / 나 / 다 / 라 | 30 / 30 / 30 / 30 | 176 / 137 / 106 / 81 | 81 / 59 / 44 / 37 |

- 신청자 기본값(책임연구원)은 **책임급** 행을 적용한다.
- 항공료: 책임급·선임급 이하는 실비(Economy), (본)부장 이상·임원은 실비(Business).

## 2. 국가·도시별 등급

여비표 비고를 따른다. **가 등급은 국가가 아니라 특정 도시**임에 주의한다.

- **가 등급(도시)**: 도쿄, 뉴욕, 런던, 로스엔젤레스, 모스크바, 샌프란시스코, 워싱턴 D.C., 파리, 홍콩, 제네바, 싱가포르
- **나 등급(국가)**: 미국, 캐나다, 일본, 인도, 오스트레일리아, 영국, 독일, 프랑스, 이탈리아, 스페인, 스위스, 네덜란드 등 (서유럽·북미 다수)
- **다 등급(국가)**: 중국, 말레이시아, 인도네시아, 타이, 터키, 브라질, 체코, 폴란드 등
- **라 등급(국가)**: 베트남, 필리핀, 몽골, 캄보디아, 페루, 콜롬비아 등

판정 규칙:
- 출장 도시가 가 등급 도시 목록에 있으면 **가 등급**.
- 아니면 출장 국가의 등급을 적용 (예: 미국 보스턴 → 보스턴은 가 도시 아님 → 미국 = **나 등급**).
- 목록에 없는 국가는 가장 가까운 국가의 등급을 적용 (여비표 비고 2).
- 애매하면 여비표 원본을 다시 확인하고, 그래도 불명확하면 사용자에게 확인한다.

## 3. 계산 산식

```
일비   = 일비단가($)  × 일수   × 환율
식비   = 식비단가($)  × 일수   × 환율
숙박비 = 숙박비단가($) × 숙박일수 × 환율
왕복교통비 = 항공인보이스의 실제 결제 금액 (원화)
합계   = 왕복교통비 + 일비 + 식비 + 숙박비
```

- **일수**: 일비·식비에 적용하는 현지 활동일수. 항공인보이스의 출국·귀국일로 출장 총일수를
  구하고 KIMM 규정에 따라 산정한다 (예시는 7일 출장에 6일 적용).
- **숙박일수**: 실제 숙박 박수 (예: 5박 7일 → 5).
- **환율**: 작성 시점 기준 매매기준율. 사용자가 환율을 주면 그 값을, 없으면 작성일 환율을
  WebSearch로 확인하고 `$1=____원 (YYYY년 MM월 DD일 기준)`으로 명시한다.
- 금액은 원 단위 반올림.

## 4. 출력 형식

양식의 소요경비 표 칸에 들어가는 산식 표기는 양식 기존 형식을 따른다:
```
일      비 : $35 x 6 = (35 * 1,480 * 6) = 310,800 원
식      비 : $78 x 6 = (78 * 1,480 * 6) = 692,640 원
숙  박  비 : $160 x 5 = (160 * 1,480 * 5) = 1,184,000 원
왕복교통비 : 2,806,800 원  (항공좌석 등급 : 이코노미)
합      계 : (왕복교통비 + 일비 + 식비 + 숙박비) 원
```

마크다운 초안에서는 `examples/`의 소요경비 표 형식(`항목 / 산식 / 금액`)을 사용한다.

표 아래 근거 문구:
```
<출장국>: 국가 및 도시별 등급 기준 <가|나|다|라> 등급지
환율: $1=____원 (YYYY년 MM월 DD일 기준)
<별표 제2-1호> 해외출장 여비 정액표 기준
```

## 5. 검산

- 책임급 + 나 등급 예: 일비 $35, 숙박 $160, 식비 $78 → 미국(보스턴) 출장의 정상값.
- `--md-only`가 아니어도 예산이 불확실하면 사용자에게 환율·일수·왕복교통비를 확인한다.
