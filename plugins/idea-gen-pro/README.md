# idea-gen-pro

연구·공학 아이디어를 비판적으로 검토하고 발전시키는 플러그인.

## 기능

- 아이디어 재진술(Restate)로 의도 정합성 확인
- 5개 평가축(과학성·기술성·신규성·실용성·자원) 점수화
- 카테고리별 약점 분석 + Reviewer 지적 가능성 표기
- 약점별 단/중/장기 보완 방안과 trade-off 명시
- WebSearch 기반 선행연구·특허 조사 (Google Scholar / arXiv / KIPRIS / USPTO 등)
- 최종 GO / PIVOT / KILL 판정과 다음 액션 제시

## 사용법

대화 중 아이디어를 던지면 자동으로 트리거된다.

```
이 연구 아이디어 어때? 초음파 영상에 ...
이거 말이 되나? 강화학습으로 ...
I'm thinking of using diffusion models for ...
```

또는 슬래시 커맨드로 명시적으로 실행한다.

```
/idea-gen-pro:develop <아이디어 텍스트 또는 .md 경로>
```

## 사용 시점

- 브레인스토밍, 제안서 기획, 논문 주제 잡기
- 아이디어의 신규성·실현성 점검
- Reviewer 관점에서의 사전 비판

## 사용하지 않을 때

- 코드 리뷰, 문서 편집, 단순 사실 질문
