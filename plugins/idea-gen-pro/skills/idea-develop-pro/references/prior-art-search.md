# 선행연구·특허 조사 가이드 (prior-art-search)

Phase 5 진입 시 본 파일을 먼저 읽고 절차를 그대로 따른다.

## 절대 원칙

- **WebSearch 도구를 반드시 호출한다.** 모델 기억에 의존한 "X 연구가 있을 것 같다"는 금지.
- 검색 결과가 0건이면 키워드를 바꿔 최소 2회 재시도 후 0건임을 명시한다.
- URL을 가공·축약하지 않고 원형 그대로 인용한다.

## 키워드 설계

1. 아이디어를 **(문제 도메인) × (방법 핵심) × (적용 대상)** 3축으로 분해한다.
2. 각 축에서 1~2개 키워드를 뽑아 **3~5개 키워드 조합** 1세트를 만든다.
3. **한국어 / 영어 모두** 조합한다.
4. 동의어·상위어·약어를 1세트씩 더 만들어 **최소 3세트**를 검색한다.

예시 (의료영상 + 자가진단 + LLM):

- 세트 A: `point-of-care ultrasound` `self-screening` `multimodal LLM`
- 세트 B: `휴대용 초음파` `자가검진` `대형언어모델`
- 세트 C: `handheld ultrasound` `home triage` `vision language model`

## 검색 대상 DB (우선순위)

| 우선 | 대상 | 검색 키워드 보조 |
|---|---|---|
| 1 | Google Scholar / arXiv | 학술 키워드 그대로 |
| 2 | PubMed (의·생명) / IEEE Xplore (공학) | 도메인에 맞춰 선택 |
| 3 | Google Patents | "method of …", IPC/CPC 분류 코드 추가 시 정밀도 향상 |
| 4 | KIPRIS (국내 특허) / USPTO (미국 특허) | 한국·미국 우선권 확인 |
| 5 | NTIS / IRIS (국내 R&D 과제) | 직접 검색 어려우면 사용자에게 키워드만 제시 |

**최근 2~3년 논문 우선**, 그 이전이라도 분야의 핵심 인용 논문 1~2개는 포함한다.

## 결과 평가 기준

각 결과를 **유사도 3등급**으로 분류한다.

- **높음** — 문제·방법·평가가 거의 동일. 신규성 위협.
- **중간** — 1~2개 축이 겹치지만 나머지가 다름. 차별화 여지 있음.
- **낮음** — 도메인·키워드 일치만 있고 본질적으로 다른 접근. 참고용.

## 보고 형식 (각 결과)

```
**[유사도: 높음/중간/낮음] 저자(연도) — 제목**
- 무엇이 비슷한가: ...
- 무엇이 다른가 (= 차별화 가능 지점): ...
- 출처: [URL]
```

검색 결과 본문은 **3~7건**으로 큐레이션 (너무 적거나 너무 많지 않게). 단, "높음" 분류 결과는 누락하지 않는다.

## 신규성 판정 규칙

| 판정 | 조건 |
|---|---|
| Strong | "높음" 0건, "중간" ≤ 2건 |
| Moderate | "높음" 0건, "중간" 3건 이상 |
| Weak | "높음" 1건 |
| 이미 존재 | "높음" 2건 이상 또는 동일 특허 등록 확인 |

판정 결과에 따라 차별화 포지셔닝 문장을 1~2문장으로 명시한다(예: "기존 X와 달리 Y 데이터·Z 평가축을 도입").

## 자주 빠지는 함정

- 영어 키워드만 검색 → 국내 KIPRIS/NTIS 누락. 한국어 검색 필수.
- 최근 3년만 검색 → 분야 정의 논문 누락. 핵심 인용 논문 1~2개는 별도로 확인.
- 특허 검색 누락 → 학술 신규성은 있어도 특허 회피가 불가능한 경우 발생.
- "비슷해 보이는" 1건만 보고 KILL 판정 → 반드시 3건 이상 비교 후 판정한다.
