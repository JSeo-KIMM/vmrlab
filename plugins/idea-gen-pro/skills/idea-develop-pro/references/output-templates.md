# 출력 템플릿 (output-templates)

각 Phase의 출력 형식 표준이다. Phase 본문을 작성할 때 그대로 사용한다.

## Phase 1 — 재진술 블록

```
**핵심 주장 (Claim)**: [한 문장]
**제안 방법 (Method)**: [한 문장]
**해결 대상 문제 (Problem)**: [한 문장]
**암묵적 가정 (Assumptions)**:
- [가정 1]
- [가정 2]
- [가정 3] (3~5개)
```

재진술이 의도와 다르면 이 블록 대신 **확인 질문 1~2개**만 출력하고 Phase 2 진입을 보류한다.

## Phase 2 — 타당성 평가 표

| 평가축 | 점수 (1~5) | 근거 (1~2문장) |
|---|---|---|
| 과학적 타당성 | x/5 | ... |
| 기술적 실현성 | x/5 | ... |
| 신규성 (예비) | x/5 | ... |
| 임상/실용 가치 | x/5 | ... |
| 자원 실현성 | x/5 | ... |

표 아래 **종합 코멘트 3문장 이내**.

## Phase 3 — 약점 카드

해당하는 항목만 출력한다. 없는 카테고리는 생략한다.

```
**[카테고리] 약점 제목**
- 무엇이 문제인가: ...
- 왜 문제인가: ...
- Reviewer가 지적할 가능성: 높음 / 중간 / 낮음
```

카테고리 후보: `논리`·`기술 병목`·`데이터`·`일반화`·`평가 방법`·`규제·윤리`·`재현성`·`경쟁 우위 소멸`.

## Phase 4 — 보완 카드

Phase 3의 모든 약점 각각에 대해 1장.

```
**약점: [Phase 3 약점 제목] → 보완**
- 단기 (논문/제안서 단계 즉시 반영): ...
- 중기 (1~6개월 추가 실험): ...
- 장기 (스코프 재정의 필요): ...
- Trade-off: 보완 시 잃는 것 / 추가 비용
```

일반론 금지. 구체적 수치·방법·데이터셋명·실험 설계까지 명시한다.

## Phase 5 — 선행연구 결과 카드

검색된 항목별로 다음 형식.

```
**[유사도: 높음 / 중간 / 낮음] 저자(연도) — 제목**
- 무엇이 비슷한가: ...
- 무엇이 다른가 (= 차별화 가능 지점): ...
- 출처: [URL]
```

마지막에 종합 블록.

```
**신규성 판정**: Strong / Moderate / Weak / 이미 존재
**차별화 포지셔닝**: [1~2문장]
```

## Phase 6 — 최종 판정 블록

```
## 종합 판정

**판정**: GO / PIVOT / KILL
- GO — 약점이 있으나 보완 가능, 신규성 확보
- PIVOT — 핵심 통찰은 살리되 스코프/방법론 재설계 필요
- KILL — 선행연구로 신규성 소실 또는 본질적 결함

**가장 큰 리스크 3가지**:
1. ...
2. ...
3. ...

**다음 액션 3가지** (우선순위 순):
1. ...
2. ...
3. ...
```
